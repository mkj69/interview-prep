45 分钟 coding 面试的标准流程

一句话

面试官打分看的是过程：澄清 → 举例 → 暴力解 → 优化 → 写代码 → 手动测试 → 复杂度。跳过前三步直接写，是最常见的失分方式。

Interviewers grade the process: clarify, work an example, state a brute force, optimize, code, test by hand, and analyze complexity. Jumping straight into code is the most common way to lose points.

阶段时间做什么面试官在看什么
1. Clarify 澄清2–4 min复述题意；问输入范围（n 多大？有负数？有重复？空输入？）、输出格式（下标还是值？顺序？）、能否修改输入沟通能力；不会想当然
2. Examples 举例2–3 min自己构造一个小例子 + 一个边界例子，手算答案真正理解题意
3. Brute force 暴力1–2 min说出最直接的解法及其复杂度（不一定要写）至少能给出一个正确解
4. Optimize 优化5–10 min识别题型（§18 速查表），说出优化思路，得到面试官认可后再写算法能力；能接受提示
5. Code 写代码10–15 min边写边讲；先写主干，辅助函数可以先留签名代码质量：命名、结构、没有低级错误
6. Test 测试3–5 min用第 2 步的例子逐行走一遍代码（dry run）；再试边界：空、单元素、全相同、最大值能自己发现 bug
7. Complexity 复杂度1 min时间和空间，说明理由（"每个元素进出栈一次"）分析能力
8. Follow-up 追问剩余时间变体、扩展到大数据、并发等深度
直觉面试官给的反馈表通常分几个维度（沟通、问题求解、代码、测试）。一道题没做完但过程清晰、沟通良好，往往比默默写出正确答案得分更高。反过来，写对了但没测试、没说复杂度，会被扣分。

卡住时怎么办

  1. 回到例子：手动在更小/更特殊的例子上模拟，观察规律。
  2. 问自己"暴力解的瓶颈在哪？内层循环在找什么？"——这几乎总能导向哈希、排序、堆或单调结构。
  3. 按题型清单过一遍：能排序吗？能二分答案吗？是图吗？有重叠子问题吗？
  4. 把思路说出来，主动请求提示："I'm considering X but I'm worried about Y — am I on the right track?" 接受提示不丢人，沉默才丢分。
常见误区(1) 题目没问清就写，写到一半发现理解错了；(2) 想到优化解就闷头写，面试官其实想先听思路；(3) 测试时只"看"代码说"looks right"，而不是用具体数值逐行跟踪变量；(4) 代码里用 a、b、tmp2 这种名字——RS 面试也看代码可读性。
Say it in English

Before I start coding, let me make sure I understand the problem. So the input is an unsorted array of integers, possibly with duplicates and negatives, and I need to return the indices, not the values — is that right? Let me try a small example by hand. The brute-force approach would check every pair, which is O(n squared). I think we can do better with a hash map; let me explain the idea first, and if that sounds good to you I'll start coding.

追问链
  1. What if you only have 20 minutes left and haven't found the optimal solution?
    思路
    先把暴力解写出来（保证有一个可运行的正确解），同时说明你知道它的瓶颈在哪、优化方向是什么。"Let me code the O(n²) version first so we have something correct, and then I'll optimize the inner loop." 这比什么都没写好得多。
  2. Can you write test cases for your function?
    思路
    按类别给：正常例子、边界（空、1 个元素、2 个元素）、特殊结构（全相同、已排序、逆序）、极值（最大 n、最大/最小值、负数）、无解情况。能写成 assert f(...) == ... 形式最好。

边写边说：英文表达清单

一句话

准备一套固定句式，面试时不用现场组织语言，脑子可以专心想算法。把下面的句子大声读熟。

Having stock phrases ready frees your working memory for the algorithm instead of for sentence construction.

场景句子
复述/澄清"Just to make sure I understand: …" · "Can the input be empty?" · "Are the values bounded? Can they be negative?" · "Should I return the indices or the values?" · "Is it okay to modify the input array?" · "Roughly how large can n get?"
举例"Let me walk through a small example." · "For this input I'd expect the output to be …"
暴力解"The straightforward approach is to … which is O(n²) time." · "That works, but we're doing redundant work in the inner loop."
优化"The key observation is that …" · "Since the array is sorted, we can …" · "If we precompute …, each query becomes O(1)." · "This looks like a sliding-window problem because …"
确认后再写"Does this approach sound reasonable before I start coding?"
写代码时"I'll use a dictionary mapping value to index." · "This loop maintains the invariant that …" · "I'll write a helper for this and fill it in later." · "Let me handle the edge case where … up front."
测试"Let me trace through the code with the example." · "At this point, left is 2 and right is 5, so …" · "Now let me try some edge cases: an empty array, a single element …" · "I found a bug — this should be <= instead of <."
复杂度"Time complexity is O(n log n), dominated by the sort." · "Each element is pushed and popped at most once, so the loop is amortized O(n)." · "Space is O(n) for the hash map, O(1) extra otherwise."
卡住 / 求助"Let me think about this for a moment." · "I'm considering two options: … Which direction would you like me to explore?" · "I'm not sure this handles duplicates — let me check."
取舍"We could trade memory for speed by …" · "If the input were streamed, I'd switch to a heap."
常见误区长时间沉默。即使在想，也要每 30–60 秒说一句你在想什么："I'm trying to figure out whether a greedy choice is safe here." 面试官无法给"沉默"打分。
Say it in English

The key observation is that once the window contains a duplicate, any larger window that contains it is also invalid, so the left pointer never needs to move backwards. I'll maintain a dictionary from character to its last index. At each step, if the current character was seen inside the window, I jump left past it. Let me trace through "abba" to make sure the left pointer doesn't move backwards — yes, I need a max there. Overall it's O(n) time and O(alphabet size) space.

6 周交错计划 + 间隔重做

一句话

每天 1–2 道新题 + 定期从空白文件重做旧题。按题型集中学，但每周混入旧题型做"交错练习"（interleaving），这样面试时才能识别题型。

Learn by pattern, but interleave old patterns every week and redo problems from a blank file on a spaced schedule; recognition comes from mixing, retention from re-solving.

工作日每天 2 道新题（约 1 小时），周六做"重做 + 模拟"，周日休息或只刷卡片。6 周 × 10 道 ≈ 60 道，正好覆盖所有 ★ 题（62 道）；☆/○ 题时间富余再做。

间隔重做（spaced re-solving）

"看懂答案"和"能写出来"是两回事。一道题真正掌握的标准是：隔一周后从空白文件 25 分钟内写对。建议用一个表格记录每题：日期、用时、是否需要提示、bug 类型（越界、off-by-one、忘记去重…）。重做时间点：做完后第 1 天、第 3 天、第 7 天、第 21 天（和本站卡片的间隔重复逻辑一致）。第一次做超过 30 分钟没思路就看提示 / 答案，但看完合上，自己重写一遍。

关掉 AI 补全

练习时关闭 Copilot / Cursor 等 AI 补全，甚至关闭普通的 IDE 自动补全。很多面试使用的共享编辑器（如 CoderPad 一类的工具，或纯文本文档）补全能力有限甚至没有，而你需要的肌肉记忆是"自己打出 from collections import deque、heapq.heappush(h, (d, v))"。推荐：用纯文本编辑器写，终端里用 python3 file.py 跑自己写的 assert。

每道题的标准练习动作

  1. 读题后先计时 3 分钟只想不写：说出题型和思路（用英文对自己说）。
  2. 写出解法 + 至少 3 个 assert（含边界）。
  3. 对照本页参考解：复杂度一样吗？有没有更简洁的写法？
  4. 在"错题本"里写一句话：这题的关键洞察是什么（就是本页每题的"关键洞察"行）。
常见误区(1) 刷题数量当目标——300 道"看过"不如 90 道"能默写"；(2) 一个题型连续做 10 道，感觉很顺，但混在一起就认不出来——必须交错；(3) 只在 LeetCode 网页上提交，从不在纯编辑器里写和自测；(4) 不练口头表达，面试时英文和算法同时卡。
Say it in English

My preparation was organized by pattern rather than by random problems. For each pattern I learned a template and a few representative problems, and then I re-solved them from scratch on a spaced schedule, without autocomplete, so I'd be comfortable writing code in a plain editor. I also mixed patterns in timed mock sessions, because in a real interview the hardest part is recognizing which pattern applies.

从输入规模反推复杂度

一句话

Python 每秒大约能做 \(10^7\) 量级的简单操作（比 C 慢 10–100 倍）。看 n 的范围就能猜出目标复杂度，进而猜出题型。

Python does on the order of ten million simple operations per second, so the input bound usually tells you the target complexity and therefore the likely pattern.

n 的范围目标复杂度常见方法
n ≤ 10–12O(n!)、O(n·2^n)排列回溯、状态压缩
n ≤ 20–25O(2^n)子集回溯、位掩码 DP、折半搜索
n ≤ 500O(n³)区间 DP、Floyd
n ≤ 5000O(n²)二维 DP、双重循环
n ≤ 10^5–10^6O(n log n) 或 O(n)排序、堆、二分、双指针、哈希、单调栈、前缀和
n ≥ 10^9（值域）O(log n) 或 O(1)二分答案、数学公式、快速幂

说复杂度时要说理由和主导项：例如"排序 O(n log n) 加一次线性扫描，所以总共 O(n log n)"。均摊分析（amortized）要明确说出来：动态数组 append、单调栈、滑动窗口、并查集。

Say it in English

Given that n can be up to ten to the fifth, a quadratic solution would be around ten billion operations, which is too slow, so I'm aiming for O(n log n) or better. That suggests sorting, a heap, or a single pass with a hash map. If n were at most twenty, I'd consider enumerating all subsets instead.

数组 & 哈希表：识别、模板与代表题

一句话

用 dict/set 把"再扫一遍找配对"从 O(n) 降到 O(1)：边扫边查"我需要的那个东西之前出现过没有"。

Trade space for time: a hash map turns "have I seen the complement before?" into an O(1) lookup, so a nested loop becomes a single pass.

哈希是几乎所有题的"第一反应"。核心套路只有三种：

  1. 查补数（complement lookup）：边遍历边把"已经见过的东西 → 位置/次数"存进 dict，当前元素需要的配对如果已经在 dict 里，答案就出来了。Two Sum 是原型。
  2. 分桶 / 规范化 key（canonical key）：把"等价"的东西映射到同一个 key 上，例如字母异位词排序后相同、或用 26 维计数 tuple 当 key。
  3. 计数（Counter）：频率统计，然后再配合排序、堆或者桶排序。

还有一类"不用哈希但属于数组技巧"的题：前后缀积（Product Except Self）、原地标记、从 set 里找连续段起点（Longest Consecutive）。它们的共同点是：用 O(n) 预处理换掉内层循环。

直觉暴力解通常是"对每个 i，再扫一遍找 j"。问自己：内层循环到底在找什么？如果能把"要找的东西"提前放进一个支持 O(1) 查询的结构，内层循环就消失了。

识别信号

  • 题目问"是否存在两个数/元素满足某关系"、"出现次数"、"去重"、"分组"
  • 暴力是 O(n²) 双重循环，且内层在"找某个值"
  • 要求 O(n) 时间，允许 O(n) 额外空间
  • "任意顺序返回"、"返回下标"（返回下标通常意味着不能先排序）

通用模板

def two_pass_lookup(nums, target):
    seen = {}                      # value -> index (or count)
    for i, x in enumerate(nums):
        need = target - x          # what would complete a pair with x?
        if need in seen:           # O(1) average
            return [seen[need], i]
        seen[x] = i                # insert AFTER the check (avoid using x twice)
    return []

from collections import Counter, defaultdict
def group_by_key(items, key_fn):
    groups = defaultdict(list)
    for it in items:
        groups[key_fn(it)].append(it)
    return list(groups.values())

复杂度：时间 O(n)（平均；哈希最坏 O(n) 每次但面试默认平均），空间 O(n)。分组题如果 key 是排序后的字符串，单个长度 k 需要 O(k log k)，总共 O(n·k log k)；用 26 维计数 tuple 则是 O(n·k)。

常见误区
  • 先 seen[x] = i 再查 need in seen，会把同一个元素用两次（target = 2x 时出错）。
  • list 不能当 dict key（不可哈希），要转成 tuple。
  • "返回下标"时不要先排序（下标会乱）；如果非要排序，要把 (value, index) 一起排。
  • Longest Consecutive 里如果对每个数都向后扩展而不是只从"段起点"扩展，会退化成 O(n²)。
Say it in English

For problems like this my first instinct is to ask what the inner loop of the brute-force solution is actually searching for. If it's searching for a specific value, I can precompute those values into a hash map and turn the O(n squared) scan into a single O(n) pass. The trade-off is O(n) extra memory, and I should mention that hash lookups are O(1) on average but can degrade with adversarial collisions. I also have to be careful about the order of "check, then insert" so I don't pair an element with itself.

追问链
  1. What if the input array is sorted, or you must use O(1) extra space?
    思路
    排好序就用双指针（见 §2，LC 167），O(n) 时间 O(1) 空间；没排序且要求 O(1) 空间，只能先排序 O(n log n)，但会丢失原下标（需排序 (value, index) 对，那又是 O(n) 空间）。
  2. What is the worst case of a hash map lookup, and when could it happen?
    思路
    最坏 O(n)：大量 key 哈希冲突（对抗性输入、差的哈希函数）。Python 对 str 有随机化哈希（PYTHONHASHSEED）防攻击；int 的 hash 是它本身，理论上可构造冲突。面试里说"average O(1), worst O(n)"即可。
  3. How would you do Top K Frequent if the data does not fit in memory / is a stream?
    思路
    流式：维护 Counter + 大小为 k 的最小堆；近似：Count-Min Sketch + 堆（heavy hitters），或 Misra-Gries 算法。分布式：先按 key 哈希分片，各片求局部计数，再合并（MapReduce）。

LC 1 · Two Sum

给一个整数数组和目标值，找出两个不同位置的数，使它们的和等于目标值，返回这两个下标（保证恰好一组解）。

提示（关键洞察）

对每个 x，要找的是 target - x；用 dict 存"值 → 下标"，先查后存。

参考答案 · O(n) / O(n)
def two_sum(nums, target):
    seen = {}
    for i, x in enumerate(nums):
        if target - x in seen:
            return [seen[target - x], i]
        seen[x] = i
    return []

复杂度：O(n) / O(n)

测试（确定性用例；另外还与暴力解做了随机对拍）

assert two_sum([2, 7, 11, 15], 9) == [0, 1]
assert two_sum([3, 2, 4], 6) == [1, 2]
assert two_sum([3, 3], 6) == [0, 1]
assert two_sum([-1, -2, -3, -4, -5], -8) == [2, 4]

LC 49 · Group Anagrams

把一组字符串按"由相同字母重排得到"分组，返回分组结果。

提示（关键洞察）

异位词的"规范形式"相同：排序后的字符串，或者 26 个字母的计数 tuple。用它做 dict 的 key。

参考答案 · O(n·k) / O(n·k)，k 为最长字符串长度
from collections import defaultdict
def group_anagrams(strs):
    groups = defaultdict(list)
    for s in strs:
        cnt = [0] * 26
        for ch in s:
            cnt[ord(ch) - ord('a')] += 1
        groups[tuple(cnt)].append(s)   # tuple is hashable, list is not
    return list(groups.values())

复杂度：O(n·k) / O(n·k)，k 为最长字符串长度

测试（确定性用例；另外还与暴力解做了随机对拍）

norm = lambda g: sorted(sorted(x) for x in g)
assert norm(group_anagrams(["eat","tea","tan","ate","nat","bat"])) == norm([["bat"],["nat","tan"],["ate","eat","tea"]])
assert group_anagrams([""]) == [[""]]
assert group_anagrams(["a"]) == [["a"]]

LC 347 · Top K Frequent Elements

返回数组中出现频率最高的 k 个元素（顺序不限）。

提示（关键洞察）

Counter 计数后有三种做法：排序 O(n log n)；大小为 k 的堆 O(n log k)；桶排序（频率最多为 n，按频率分桶）O(n)。

参考答案 · 桶排序 O(n) / O(n)；堆 O(n log k)
from collections import Counter
def top_k_frequent(nums, k):
    cnt = Counter(nums)
    buckets = [[] for _ in range(len(nums) + 1)]   # index = frequency
    for x, c in cnt.items():
        buckets[c].append(x)
    out = []
    for c in range(len(buckets) - 1, 0, -1):
        for x in buckets[c]:
            out.append(x)
            if len(out) == k:
                return out
    return out

import heapq
def top_k_frequent_heap(nums, k):
    cnt = Counter(nums)
    return heapq.nlargest(k, cnt.keys(), key=cnt.get)   # O(n log k)

复杂度：桶排序 O(n) / O(n)；堆 O(n log k)

测试（确定性用例；另外还与暴力解做了随机对拍）

assert sorted(top_k_frequent_heap([4,4,5,5,5,6], 2)) == [4, 5]

LC 128 · Longest Consecutive Sequence

提示（关键洞察）

放进 set；只有当 x-1 不在 set 里时，x 才是一段的起点，从起点往后数。每个数最多被"数"一次，所以总共 O(n)。

参考答案 · O(n) / O(n)
def longest_consecutive(nums):
    s = set(nums)
    best = 0
    for x in s:                 # iterate the set, not nums (duplicates!)
        if x - 1 not in s:      # x starts a run
            y = x
            while y + 1 in s:
                y += 1
            best = max(best, y - x + 1)
    return best

复杂度：O(n) / O(n)

LC 238 · Product of Array Except Self

answer[i] = 左边所有数的积 × 右边所有数的积。先正向写前缀积，再反向用一个变量乘上后缀积，额外空间 O(1)（输出数组不算）。

参考答案 · O(n) / O(1) 额外
def product_except_self(nums):
    n = len(nums)
    ans = [1] * n
    for i in range(1, n):            # ans[i] = prod(nums[:i])
        ans[i] = ans[i - 1] * nums[i - 1]
    suffix = 1
    for i in range(n - 1, -1, -1):   # multiply by prod(nums[i+1:])
        ans[i] *= suffix
        suffix *= nums[i]
    return ans

复杂度：O(n) / O(1) 额外

§2 · TWO POINTERS双指针

★

双指针：识别、模板与代表题

一句话

在有序或对称结构上，用两个指针相向或同向移动，每一步都能安全地排除一批候选，把 O(n²) 变 O(n)。

On sorted or symmetric data, two pointers let each step safely discard a whole set of candidates, turning an O(n squared) pair search into O(n).

双指针分三种：

类型移动方式典型题
相向（opposite ends）l=0, r=n-1，根据比较结果移动一端Two Sum II、3Sum、Container、回文
同向 / 快慢（read-write）slow 写入位置，fast 扫描Remove Duplicates、Move Zeroes、链表找环
三指针 / 分区Dutch National Flag：lo, i, hiSort Colors、快排 partition

正确性的关键是"排除论证"（exchange / elimination argument）：以 Container With Most Water 为例，左右两边较矮的那一边，无论另一端怎么往里移，面积都不会超过当前值（宽度变小、高度上限被它卡住），所以可以安全地丢掉它。面试时一定要把这个论证说出来，这是区分"背过题"和"理解了"的地方。

识别信号

  • 数组已排序，或可以先排序（不要求返回原下标）
  • 问"一对/三元组满足和为某值"、"回文"、"原地去重/移动"
  • 要求 O(1) 额外空间
  • 左右两端有某种单调性：移动一端时目标函数朝确定方向变化

通用模板

def opposite_ends(a, target):          # sorted a
    l, r = 0, len(a) - 1
    while l < r:
        s = a[l] + a[r]
        if s == target:
            return l, r
        if s < target:
            l += 1                     # need bigger: a[l] can't pair with anything <= a[r]
        else:
            r -= 1
    return None

def compact(a, keep):                  # same-direction read/write pointers
    w = 0
    for x in a:                        # fast pointer = loop variable
        if keep(x):
            a[w] = x
            w += 1
    return w                           # new length

复杂度：O(n)（若需要先排序则 O(n log n)），额外空间 O(1)。3Sum 为 O(n²)：外层固定一个数，内层双指针。

常见误区
  • 3Sum 去重：外层 if i > 0 and a[i] == a[i-1]: continue；内层找到解后要跳过所有相同值。
  • while l < r 还是 l <= r：两个指针不能指同一个元素时用 <。
  • Sort Colors 中，与 hi 交换后 i 不能前进（换过来的元素还没检查）。
  • Trapping Rain Water 双指针版本：移动较矮的一侧，因为它的水位由自己这一侧的最大值决定。
Say it in English

I'd use two pointers here because the array is sorted, so the sum of the two ends tells me which pointer to move. If the sum is too small, the left element can't be part of any valid pair with something to its left of the right pointer, so I can discard it safely. Each step eliminates one candidate, which gives O(n) time and O(1) extra space. The key is to articulate why discarding is safe, not just to move pointers by habit.

追问链
  1. Can you generalize 3Sum to kSum?
    思路
    递归：kSum 固定一个数后变成 (k-1)Sum，直到 2Sum 用双指针。复杂度 \(O(n^{k-1})\)。去重逻辑在每一层都要做。
  2. Trapping Rain Water: can you explain the two-pointer version versus the prefix-max version?
    思路
    前缀/后缀最大值版本：water[i] = min(leftMax[i], rightMax[i]) - h[i]，O(n) 空间。双指针版本：如果 leftMax < rightMax，左指针位置的水位已经确定是 leftMax（右边一定有更高的墙），所以可以结算左边并右移；反之结算右边。O(1) 空间。还有单调栈版本按"层"计算。

LC 15 · 3Sum

找出数组中所有和为 0 的三元组，结果中不能有重复的三元组。

提示（关键洞察）

排序；固定 a[i]，在其右侧做 Two Sum II（目标 -a[i]）。两层都要跳过重复值。a[i] > 0 时可以提前结束。

参考答案 · O(n²) / O(1)（不计排序和输出）
def three_sum(nums):
    a = sorted(nums)
    n, res = len(a), []
    for i in range(n - 2):
        if a[i] > 0:
            break
        if i > 0 and a[i] == a[i - 1]:
            continue                       # skip duplicate anchors
        l, r = i + 1, n - 1
        while l < r:
            s = a[i] + a[l] + a[r]
            if s < 0:
                l += 1
            elif s > 0:
                r -= 1
            else:
                res.append([a[i], a[l], a[r]])
                l += 1
                r -= 1
                while l < r and a[l] == a[l - 1]:
                    l += 1                 # skip duplicate second elements
    return res

复杂度：O(n²) / O(1)（不计排序和输出）

LC 42 · Trapping Rain Water

给定柱子高度图，计算下雨后柱子之间能积多少水。

提示（关键洞察）

每个位置的水量 = min(左侧最高, 右侧最高) − 自身高度。双指针：哪边的最大值更小，那一边当前位置的水位就已确定，结算并移动那一边。

参考答案 · O(n) / O(1)
def trap(h):
    l, r = 0, len(h) - 1
    lmax = rmax = water = 0
    while l < r:
        if h[l] < h[r]:
            lmax = max(lmax, h[l])
            water += lmax - h[l]       # right side has a wall >= h[r] > h[l]
            l += 1
        else:
            rmax = max(rmax, h[r])
            water += rmax - h[r]
            r -= 1
    return water

复杂度：O(n) / O(1)

LC 75 · Sort Colors

原地把只含 0、1、2 的数组排成 0…1…2 的顺序，最好一趟扫描。

Dutch National Flag：[0,lo) 全是 0，[lo,i) 全是 1，(hi,n-1] 全是 2。遇 2 与 hi 交换后 i 不前进。

参考答案 · O(n) / O(1)
def sort_colors(a):
    lo, i, hi = 0, 0, len(a) - 1
    while i <= hi:
        if a[i] == 0:
            a[lo], a[i] = a[i], a[lo]
            lo += 1
            i += 1
        elif a[i] == 2:
            a[i], a[hi] = a[hi], a[i]
            hi -= 1                    # do NOT advance i: swapped-in value is unchecked
        else:
            i += 1

复杂度：O(n) / O(1)

§3 · SLIDING WINDOW滑动窗口

★

滑动窗口：识别、模板与代表题

一句话

求"满足条件的最长/最短连续子数组/子串"：右指针扩张、条件被破坏（或满足）时左指针收缩，每个元素最多进出窗口一次，O(n)。

For the longest or shortest contiguous subarray satisfying a condition, grow the right edge and shrink the left edge; each element enters and leaves the window once, so it is O(n).

滑动窗口是同向双指针的特例，适用前提是单调性：窗口变大，"违规程度"不会减小（例如重复字符只会更多、和只会更大（元素非负时））。这样左指针永远不需要后退。

  • 可变窗口求最长：扩右；当窗口不合法时收缩左，直到合法；然后用当前窗口更新答案。
  • 可变窗口求最短：扩右；当窗口合法时，更新答案并收缩左，直到不合法。
  • 固定窗口（长度 k）：右进一个、左出一个，维护计数（Permutation in String）。
  • 窗口内最值：配合单调双端队列（Sliding Window Maximum）。
直觉如果数组里有负数，"和 ≥ K 的最短子数组"就没有单调性了，滑动窗口失效，要改用前缀和 + 单调队列（LC 862）或前缀和 + 哈希。识别这一点是常见追问。

识别信号

  • "连续子数组 / 子串"（contiguous）
  • "最长 / 最短 / 恰好包含 / 至多 k 个不同"
  • 窗口扩大时某个量单调变化（元素非负、计数只增）
  • 字符串 + 字符计数

通用模板

from collections import defaultdict
def longest_valid_window(s, is_bad):
    cnt = defaultdict(int)
    l = best = 0
    for r, ch in enumerate(s):
        cnt[ch] += 1                   # 1) expand: add s[r]
        while is_bad(cnt, r - l + 1):  # 2) shrink until window is valid again
            cnt[s[l]] -= 1
            l += 1
        best = max(best, r - l + 1)    # 3) window [l, r] is valid: update answer
    return best

复杂度：O(n)：每个下标最多被 r 加入一次、被 l 移出一次（均摊）。空间 O(字符集) 或 O(k)。

常见误区
  • 求最长时在 while 之后更新答案；求最短时在 while 之内更新答案。
  • 用 sum(cnt.values()) 或 len(cnt) 判断合法性要小心：计数降为 0 时要 del 或用"已满足种类数"变量维护，避免每步 O(Σ) 的检查。
  • 有负数时窗口不单调，滑动窗口不适用。
  • Minimum Window Substring 要维护 formed（已满足的字符种类数），而不是每次比较两个 Counter。
Say it in English

This is a contiguous-subarray problem and the validity condition is monotone: if a window is invalid, any larger window containing it is also invalid. That means I can use a sliding window where the right pointer always expands and the left pointer only moves forward to restore validity. Each index is added and removed at most once, so it's linear time. I'll maintain counts incrementally so each step is O(1), rather than recounting the window.

追问链
  1. What breaks if the array contains negative numbers?
    思路
    单调性被破坏：加入负数会让和变小，窗口扩大不再意味着"更违规"。要用前缀和：求"和恰好为 k 的个数"用前缀和 + 哈希（LC 560）；求"和 ≥ k 的最短"用前缀和 + 单调双端队列（LC 862）。
  2. How do you count subarrays with exactly K distinct elements?
    思路
    exactly(K) = atMost(K) − atMost(K−1)。atMost 用滑动窗口：每个 r 贡献 r − l + 1 个以 r 结尾的合法子数组（LC 992）。

LC 424 · Longest Repeating Character Replacement

最多把 k 个字符替换成任意大写字母，求能得到的"全部相同字母"的最长子串长度。

提示（关键洞察）

参考答案 · O(n) / O(26)
from collections import Counter
def character_replacement(s, k):
    cnt = Counter()
    l = maxf = best = 0
    for r, ch in enumerate(s):
        cnt[ch] += 1
        maxf = max(maxf, cnt[ch])
        while (r - l + 1) - maxf > k:
            cnt[s[l]] -= 1
            l += 1
        best = max(best, r - l + 1)
    return best

复杂度：O(n) / O(26)

在字符串 s 中找最短的子串，使其包含 t 中所有字符（含重复次数），不存在则返回空串。

from collections import Counter
def min_window(s, t):
    if not t or not s:
        return ""
    need = Counter(t)
    have = Counter()
    required, formed = len(need), 0
    l, best = 0, (float('inf'), 0, 0)
    for r, ch in enumerate(s):
        have[ch] += 1
        if ch in need and have[ch] == need[ch]:
            formed += 1
        while formed == required:            # valid: try to shrink
            if r - l + 1 < best[0]:
                best = (r - l + 1, l, r)
            out = s[l]
            have[out] -= 1
            if out in need and have[out] < need[out]:
                formed -= 1
            l += 1
    return "" if best[0] == float('inf') else s[best[1]:best[2] + 1]

复杂度：O(|s| + |t|) / O(字符集)

LC 239 · Sliding Window Maximum

长度为 k 的窗口从左滑到右，输出每个位置窗口内的最大值。

参考答案 · O(n) / O(k)
from collections import deque
def max_sliding_window(nums, k):
    dq, out = deque(), []          # indices, values strictly decreasing
    for i, x in enumerate(nums):
        while dq and nums[dq[-1]] <= x:
            dq.pop()               # dominated: smaller AND older
        dq.append(i)
        if dq[0] <= i - k:
            dq.popleft()           # out of window
        if i >= k - 1:
            out.append(nums[dq[0]])
    return out

复杂度：O(n) / O(k)

§4 · PREFIX SUMS前缀和

★

前缀和：识别、模板与代表题

一句话

P[i] = a[0]+…+a[i-1]，区间和 sum(a[l:r]) = P[r]-P[l]；"和为 k 的子数组"= 找两个前缀和之差为 k，配合哈希 O(n)。

With prefix sums, any range sum is a difference of two prefixes; counting subarrays with sum k becomes counting earlier prefixes equal to the current prefix minus k.

前缀和把"区间问题"转化成"两点问题"。约定 P 长度为 n+1，P[0]=0，这样 a[l..r-1] 的和就是 P[r]-P[l]，不需要特判 l=0。

三种组合：

  • 前缀和 + 哈希：子数组和等于 k → 当前前缀 P 之前出现过多少次 P-k。适用于有负数（滑动窗口做不了的场景）。
  • 前缀和取模：子数组和是 k 的倍数 ⇔ 两个前缀和模 k 相同。
  • 二维前缀和：S[i][j] 是左上角矩形的和，查询用容斥原理。

相关推广：差分数组（区间加、单点查），是前缀和的逆运算；"前缀积 / 前缀异或 / 前缀计数"同理。

$$\text{sum}(r_1..r_2, c_1..c_2) = S[r_2+1][c_2+1] - S[r_1][c_2+1] - S[r_2+1][c_1] + S[r_1][c_1]$$

识别信号

  • "子数组和等于 / 是 k 的倍数 / 区间和查询"
  • 数组有负数，滑动窗口失效
  • 多次区间查询（预处理 O(n)，查询 O(1)）
  • "平衡"类：0 和 1 个数相等 → 把 0 当 −1 求和为 0

通用模板

from collections import defaultdict
def count_subarrays_sum_k(a, k):
    cnt = defaultdict(int)
    cnt[0] = 1                 # empty prefix: allows subarrays starting at index 0
    P = ans = 0
    for x in a:
        P += x
        ans += cnt[P - k]      # earlier prefixes Q with P - Q == k
        cnt[P] += 1            # insert AFTER counting
    return ans

复杂度：一维：预处理 O(n)，查询 O(1)；哈希版计数 O(n) 时间 O(n) 空间。二维：预处理 O(mn)，查询 O(1)。

常见误区
  • 忘记 cnt[0] = 1，会漏掉从下标 0 开始的子数组。
  • 先 cnt[P] += 1 再查 cnt[P-k]，k = 0 时会把空子数组算进去。
  • Continuous Subarray Sum 要求长度 ≥ 2：哈希里存"余数第一次出现的下标"，而不是次数；初始 {0: -1}。
  • Python 的 % 对负数返回非负结果（和 C 不同），所以负数取模不用额外处理。
Say it in English

Since the array can contain negative numbers, a sliding window won't work because the sum isn't monotone in the window size. Instead I'll use prefix sums: a subarray from i to j sums to k exactly when prefix of j minus prefix of i equals k. So as I scan, I keep a hash map from prefix-sum value to how many times I've seen it, and for each position I add the count of prefix minus k. I initialize the map with zero mapped to one to account for subarrays starting at index zero.

追问链
  1. How would you support range updates as well as range queries?
    思路
    差分数组支持 O(1) 区间加、O(n) 重建；同时要在线区间加 + 区间查询，用 Fenwick tree（树状数组，两个 BIT）或 segment tree with lazy propagation，O(log n) 每次操作。
  2. Longest subarray with sum k instead of count?
    思路
    哈希存每个前缀和第一次出现的下标，答案为 max(j − first[P−k])。

    def __init__(self, matrix):
        m = len(matrix)
        n = len(matrix[0]) if m else 0
        self.S = S = [[0] * (n + 1) for _ in range(m + 1)]
        for i in range(m):
            for j in range(n):
                S[i + 1][j + 1] = matrix[i][j] + S[i][j + 1] + S[i + 1][j] - S[i][j]

        return S[r2 + 1][c2 + 1] - S[r1][c2 + 1] - S[r2 + 1][c1] + S[r1][c1]

§5 · STACK & MONOTONIC STACK栈 & 单调栈

★

栈 & 单调栈：识别、模板与代表题

一句话

栈处理"最近的未匹配项"（括号、表达式）；单调栈在 O(n) 内为每个元素找到左/右侧第一个比它大（或小）的元素。

A stack handles "most recent unmatched item" problems; a monotonic stack finds, for every element, the nearest greater or smaller element in one O(n) pass.

普通栈：后进先出，天然对应"嵌套结构"——括号匹配、表达式求值、撤销操作、DFS 的显式模拟。

单调栈：栈中元素（通常存下标）保持单调。新元素 x 进来前，把所有"被 x 支配"的栈顶弹出——被弹出的元素此刻找到了它的"右侧第一个更大值"就是 x。每个下标入栈一次、出栈一次，所以总共 O(n)。

要找栈内单调性（从底到顶）弹出条件
右侧第一个更大递减a[st[-1]] < x
右侧第一个更小递增a[st[-1]] > x
左侧第一个更大/更小同上弹完后的栈顶就是答案
直觉想象一排人看向右边：一个人如果比他左边的人都高，那左边比他矮的人"往右看到的第一个更高的人"就是他，而且这些矮个子以后再也不会被谁需要了——所以可以弹掉。

识别信号

  • 括号/嵌套/"最近的"匹配
  • "下一个更大/更小元素"、"还要等几天"
  • 柱状图最大矩形、接雨水（按层）
  • 需要 O(1) 取最小值的栈（辅助栈）
  • 后缀表达式求值、字符串解码 3[a2[c]]

通用模板

def next_greater(a):
    n = len(a)
    res = [-1] * n                     # index of next greater element, -1 if none
    st = []                            # indices; a[st] strictly decreasing
    for i, x in enumerate(a):
        while st and a[st[-1]] < x:
            res[st.pop()] = i          # x is the first greater to the right
        st.append(i)
    return res

复杂度：O(n) 时间（每个元素进出栈各一次），O(n) 空间。

常见误区
  • 栈里存下标而不是值（需要算距离/宽度）。
  • 严格 < 还是 <= 决定相等元素如何处理；Largest Rectangle 中两者都对，但要想清楚。
  • Largest Rectangle 常用技巧：在末尾加一个高度 0 的哨兵，强制清空栈。
  • Evaluate RPN 中除法要向零截断：Python 用 int(a / b)，不能用 //。
Say it in English

I'll use a monotonic stack of indices that keeps the values in decreasing order. When a new element arrives, every smaller element on top of the stack has just found its next greater element, so I pop it and record the answer. Since each index is pushed and popped at most once, the whole thing is O(n) even though there's a nested while loop.

追问链
  1. Why is the nested while loop still O(n)?
    思路
    均摊分析：每个下标最多 push 一次、pop 一次，所有 while 迭代的总次数 ≤ n，所以总时间 O(n)（aggregate / amortized analysis）。
  2. Next greater element in a circular array?
    思路
    遍历两遍（下标 i % n），第二遍只弹不压（或者压了也无妨），LC 503。

        m = min(val, self.st[-1][1]) if self.st else val
        self.st.append((val, m))

        self.st.pop()
    def top(self):
        return self.st[-1][0]
    def getMin(self):
        return self.st[-1][1]

def eval_rpn(tokens):
    st = []
    for t in tokens:
        if t in ('+', '-', '*', '/'):
            b = st.pop()
            a = st.pop()               # a op b
            if t == '+': st.append(a + b)
            elif t == '-': st.append(a - b)
            elif t == '*': st.append(a * b)
            else: st.append(int(a / b))   # truncate toward zero (NOT //)
        else:
            st.append(int(t))
    return st[0]

LC 84 · Largest Rectangle in Histogram

参考答案 · O(n) / O(n)
def largest_rectangle_area(heights):
    hs = heights + [0]                     # sentinel 0 flushes the stack at the end
    st = []                                # indices, heights increasing
    best = 0
    for i, h in enumerate(hs):
        while st and hs[st[-1]] >= h:
            j = st.pop()                   # bar j: right limit i, left limit new top
            left = st[-1] if st else -1
            best = max(best, hs[j] * (i - left - 1))
        st.append(i)
    return best

二分查找 & 二分答案：识别、模板与代表题

一句话

二分的本质不是"有序数组找值"，而是在单调的布尔函数上找第一个 True。固定用 [lo, hi) 半开区间 + lower_bound 模板，几乎不会写错。

Binary search finds the first index where a monotone predicate flips from False to True; with one half-open lower-bound template you can solve sorted search, rotated arrays, and "binary search on the answer".

把所有二分题都转化成：定义一个单调谓词 ok(x)（F F F … T T T），找第一个 T。

  • 有序数组找 target：ok(i) = a[i] >= target，找到后检查 a[i] == target。
  • 旋转数组找最小值：ok(i) = a[i] <= a[-1]（最小值及其右边都 ≤ 最后一个元素）。
  • 二分答案：答案 x 越大越容易满足（或越难），例如"速度 x 能否在 h 小时内吃完"是单调的 → 在答案空间 [lo, hi] 上二分。

不变式（invariant）：[lo_init, lo) 全是 F，[hi, hi_init) 全是 T。循环 while lo < hi，mid = (lo+hi)//2，ok(mid) 为真则 hi = mid，否则 lo = mid+1。结束时 lo == hi 就是第一个 T（若不存在则是 hi_init）。

直觉每一步都把搜索区间严格缩小（mid < hi，所以 hi=mid 缩小；lo=mid+1 也缩小），所以不会死循环；不变式保证不会丢答案。面试时说出不变式，比"我背了模板"有说服力得多。

识别信号

  • 有序 / 部分有序（旋转）数组
  • 要求 O(log n)
  • "最小的最大值 / 最大的最小值"、"最少需要多少速度/天数/容量"（二分答案）
  • 答案范围大但判定可行性容易（判定是 O(n) 的贪心）

通用模板

def first_true(lo, hi, ok):
    """Smallest x in [lo, hi) with ok(x) True; returns hi if none. ok must be F..F T..T."""
    while lo < hi:
        mid = (lo + hi) // 2
        if ok(mid):
            hi = mid
        else:
            lo = mid + 1
    return lo

def lower_bound(a, target):              # == bisect.bisect_left(a, target)
    return first_true(0, len(a), lambda i: a[i] >= target)

复杂度：O(log n) 次判定；二分答案总复杂度 O(判定成本 × log(答案范围))。

常见误区
  • lo = mid（而非 mid+1）配合 mid = (lo+hi)//2 会死循环——用统一模板避免。
  • Python 没有整数溢出，但写 C++/Java 时要用 lo + (hi-lo)/2；面试时顺口提一句加分。
  • 二分答案时 hi 要取到"一定可行"的值（如 Koko 中 max(piles)），并想清楚是找第一个可行还是最后一个可行。
  • 旋转数组有重复元素时（LC 81/154），最坏退化为 O(n)，因为 a[mid] == a[hi] 时无法判断方向，只能 hi -= 1。
Say it in English

I like to frame binary search as finding the first position where a monotone predicate becomes true. I keep a half-open interval with the invariant that everything left of lo is false and everything from hi onward is true. Each iteration shrinks the interval, so it terminates, and when lo equals hi that's the boundary. For this problem the predicate is "can we finish within h hours at speed k", which is monotone in k, so I can binary search over the answer space.

追问链
  1. How would you find the last occurrence of target?
    思路
    找第一个 > target 的位置（bisect_right），再减 1，并检查该位置的值是否等于 target。
  2. Binary search on real numbers?
    思路
    固定迭代次数（如 100 次）或 while hi - lo > eps；每次 mid = (lo+hi)/2，按 ok(mid) 收缩。例：求 sqrt、最小化最大距离。
  3. Why is Median of Two Sorted Arrays O(log(min(m, n)))?
    思路
    在较短数组上二分"切分点" i，另一数组切分点 j = (m+n+1)/2 − i 被确定；检查 left_max ≤ right_min 的单调条件。见下方 LC 4。

LC 33 · Search in Rotated Sorted Array

在旋转过的升序无重复数组中查找目标值的下标，要求 O(log n)。

提示（关键洞察）

mid 把数组切成两半，至少一半是有序的。判断 target 是否落在有序那一半的范围内，决定往哪边走。（也可以先用 153 找旋转点，再在一段内普通二分。）

参考答案 · O(log n) / O(1)
def search_rotated(a, target):
    lo, hi = 0, len(a) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if a[mid] == target:
            return mid
        if a[lo] <= a[mid]:                    # left half [lo, mid] sorted
            if a[lo] <= target < a[mid]:
                hi = mid - 1
            else:
                lo = mid + 1
        else:                                  # right half [mid, hi] sorted
            if a[mid] < target <= a[hi]:
                lo = mid + 1
            else:
                hi = mid - 1
    return -1

复杂度：O(log n) / O(1)

def min_eating_speed(piles, h):
    def ok(k):
        return sum((p + k - 1) // k for p in piles) <= h
    lo, hi = 1, max(piles)           # hi is always feasible (h >= len(piles))
    while lo < hi:
        mid = (lo + hi) // 2
        if ok(mid):
            hi = mid
        else:
            lo = mid + 1
    return lo

LC 4 · Median of Two Sorted Arrays

求两个有序数组合并后的中位数，要求 O(log(m+n))。

提示（关键洞察）

在较短数组 A 上二分切分点 i（左边取 i 个），B 取 j = half − i 个。合法切分满足 A[i−1] ≤ B[j] 且 B[j−1] ≤ A[i]。用 ±inf 处理边界。

参考答案 · O(log min(m,n)) / O(1)
def find_median_sorted_arrays(A, B):
    if len(A) > len(B):
        A, B = B, A
    m, n = len(A), len(B)
    half = (m + n + 1) // 2
    lo, hi = 0, m
    INF = float('inf')
    while lo <= hi:
        i = (lo + hi) // 2               # elements taken from A on the left
        j = half - i
        Al = A[i - 1] if i > 0 else -INF
        Ar = A[i] if i < m else INF
        Bl = B[j - 1] if j > 0 else -INF
        Br = B[j] if j < n else INF
        if Al <= Br and Bl <= Ar:
            if (m + n) % 2:
                return float(max(Al, Bl))
            return (max(Al, Bl) + min(Ar, Br)) / 2
        if Al > Br:
            hi = i - 1                   # took too many from A
        else:
            lo = i + 1
    raise ValueError("inputs not sorted")

复杂度：O(log min(m,n)) / O(1)

测试（确定性用例；另外还与暴力解做了随机对拍）

assert find_median_sorted_arrays([1,3], [2]) == 2.0
assert find_median_sorted_arrays([1,2], [3,4]) == 2.5
assert find_median_sorted_arrays([], [1]) == 1.0
assert find_median_sorted_arrays([2], []) == 2.0

§7 · LINKED LIST链表

★

链表：识别、模板与代表题

一句话

链表题考的是指针操作不出错：用 dummy 头节点消除边界、快慢指针找中点/环、画图后再写代码。

Linked-list questions test careful pointer manipulation: use a dummy head to remove edge cases, fast and slow pointers for middles and cycles, and draw the pointers before coding.

C 程序员在这里有天然优势——Python 里 node.next 就是 C 的 node->next，只是没有显式指针语法。几个通用技巧：

  • Dummy（哨兵）头节点：dummy = ListNode(0, head)，最后返回 dummy.next。头节点可能被删除/替换时必用。
  • 快慢指针：fast 每次两步、slow 每次一步。fast 到尾时 slow 在中点；有环则必相遇（Floyd）。
  • 先后差 n 步：删除倒数第 n 个。
  • 原地反转：三个变量 prev, cur, nxt，是很多题的子程序（回文链表、K 个一组反转、重排链表）。

Floyd 判环找入口的证明：设头到入口距离 a，入口到相遇点 b，环长 c。相遇时 slow 走了 a+b，fast 走了 2(a+b)，且 fast 多走整数圈：\(a+b = kc\)。所以 \(a = kc - b\)：从相遇点再走 a 步恰好到入口（走 c−b 到入口，再绕 k−1 圈）。于是一个指针从头、一个从相遇点同速走，相遇处就是入口。

识别信号

  • 题目给 ListNode
  • "原地"、"O(1) 空间"
  • 找中点、判环、倒数第 k 个
  • 需要 O(1) 删除/移动的设计题（LRU = 哈希 + 双向链表）

通用模板

def reverse_list(head):
    prev, cur = None, head
    while cur:
        nxt = cur.next      # save
        cur.next = prev     # reverse pointer
        prev, cur = cur, nxt
    return prev

def middle(head):            # second middle for even length
    slow = fast = head
    while fast and fast.next:
        slow, fast = slow.next, fast.next.next
    return slow

复杂度：大多 O(n) 时间 O(1) 空间；递归反转需要 O(n) 栈空间（Python 默认递归上限约 1000，长链表会爆）。

常见误区
  • 修改 cur.next 之前没有先保存 nxt，链表断掉。
  • while fast and fast.next 两个条件缺一不可。
  • 删除节点需要拿到它的前驱——所以用 dummy，并让指针停在前驱上。
  • LRU 用 OrderedDict 可以，但面试官常要求手写双向链表；两种都要会。
Say it in English

I'll add a dummy node in front of the head so that removing or replacing the first node isn't a special case. Then I'll walk with two pointers: the fast one moves n steps ahead first, and then both move together until the fast one hits the end, so the slow one stops right before the node to remove. Let me draw the pointers on a small example first so I don't lose a reference when I rewire next.

LC 206 · Reverse Linked List

反转一个单链表。

提示（关键洞察）

迭代三指针（见模板）；递归版：new = rev(head.next); head.next.next = head; head.next = None。

参考答案 · O(n) / 迭代 O(1)，递归 O(n)
def reverse_iter(head):
    prev, cur = None, head
    while cur:
        cur.next, prev, cur = prev, cur, cur.next   # RHS evaluated first
    return prev

def reverse_rec(head):
    if not head or not head.next:
        return head
    new_head = reverse_rec(head.next)
    head.next.next = head      # the node after head now points back
    head.next = None
    return new_head

复杂度：O(n) / 迭代 O(1)，递归 O(n)

def merge_two_lists(a, b):
    dummy = tail = ListNode()
    while a and b:
        if a.val <= b.val:
            tail.next, a = a, a.next
        else:
            tail.next, b = b, b.next
        tail = tail.next
    tail.next = a or b
    return dummy.next

LC 141 · Linked List Cycle

判断链表中是否有环。（进阶：LC 142 返回环的入口。）

提示（关键洞察）

Floyd 快慢指针；找入口时，相遇后一个指针回到头，两者同速前进。

参考答案 · O(n) / O(1)
def has_cycle(head):
    slow = fast = head
    while fast and fast.next:
        slow, fast = slow.next, fast.next.next
        if slow is fast:
            return True
    return False

def detect_cycle(head):          # LC 142
    slow = fast = head
    while fast and fast.next:
        slow, fast = slow.next, fast.next.next
        if slow is fast:
            p = head
            while p is not slow:
                p, slow = p.next, slow.next
            return p
    return None

复杂度：O(n) / O(1)

def remove_nth_from_end(head, n):
    dummy = ListNode(0, head)
    slow = fast = dummy
    for _ in range(n + 1):
        fast = fast.next
    while fast:
        slow, fast = slow.next, fast.next
    slow.next = slow.next.next
    return dummy.next

LC 146 · LRU Cache

设计一个容量固定的 LRU 缓存，get 和 put 均为 O(1)；满了时淘汰最久未使用的键。

提示（关键洞察）

哈希表（key → 节点）+ 双向链表（按最近使用排序，头部最新、尾部最旧）。两个哨兵节点消除边界。也给出 OrderedDict 版本。

参考答案 · 每次操作 O(1) / O(capacity)
class Node:
    __slots__ = ('key', 'val', 'prev', 'next')
    def __init__(self, key=0, val=0):
        self.key, self.val = key, val
        self.prev = self.next = None

class LRUCache:
    def __init__(self, capacity):
        self.cap = capacity
        self.map = {}
        self.head, self.tail = Node(), Node()      # sentinels
        self.head.next, self.tail.prev = self.tail, self.head

    def _remove(self, node):
        node.prev.next, node.next.prev = node.next, node.prev

    def _add_front(self, node):
        node.prev, node.next = self.head, self.head.next
        self.head.next.prev = node
        self.head.next = node

    def get(self, key):
        if key not in self.map:
            return -1
        node = self.map[key]
        self._remove(node)
        self._add_front(node)
        return node.val

    def put(self, key, value):
        if key in self.map:
            self._remove(self.map[key])
        node = Node(key, value)
        self.map[key] = node
        self._add_front(node)
        if len(self.map) > self.cap:
            lru = self.tail.prev
            self._remove(lru)
            del self.map[lru.key]

        self.cap, self.od = capacity, OrderedDict()
    def get(self, key):
        if key not in self.od:
            return -1
        self.od.move_to_end(key)
        return self.od[key]
    def put(self, key, value):
        self.od[key] = value
        self.od.move_to_end(key)
        if len(self.od) > self.cap:
            self.od.popitem(last=False)     # pop least recently used

复杂度：每次操作 O(1) / O(capacity)

§8 · BINARY TREES二叉树 & BST

★

二叉树 & BST：识别、模板与代表题

一句话

树题 = 想清楚"递归函数返回什么"。大多数题是后序遍历：先拿到左右子树的结果，再在当前节点合并；BST 题利用中序有序或上下界。

Most tree problems reduce to defining what the recursive function returns for a subtree, then combining left and right results at the current node; for BSTs, use in-order sortedness or min/max bounds.

写树递归的三问：

  1. 函数的定义：f(node) 返回关于"以 node 为根的子树"的什么信息？（高度？是否平衡？经过它的最大路径和？）
  2. base case：node is None 返回什么？
  3. 合并：已知 f(left)、f(right)，怎么得到 f(node)？是否需要额外更新一个全局答案（比如直径、最大路径和——"经过当前节点"的答案和"返回给父节点"的值不一样）？
遍历何时用
前序（根左右）自顶向下传参数（深度、路径、上下界）、序列化
中序（左根右）BST 得到有序序列（验证 BST、第 k 小）
后序（左右根）需要子树信息（高度、直径、路径和、LCA）
层序（BFS）按层输出、右视图、最短深度

识别信号

  • 题目给 TreeNode
  • "深度 / 路径 / 直径 / 是否平衡 / 公共祖先"
  • BST：中序有序、左小右大
  • "按层"→ BFS

通用模板

def solve(root):
    best = float('-inf')                 # global answer (if needed)
    def dfs(node):
        nonlocal best
        if node is None:
            return 0                     # base case value
        L, R = dfs(node.left), dfs(node.right)
        best = max(best, L + R)          # answer "through" this node
        return 1 + max(L, R)             # value returned to the parent
    dfs(root)
    return best

from collections import deque
def level_order(root):
    if not root:
        return []
    res, q = [], deque([root])
    while q:
        level = []
        for _ in range(len(q)):          # snapshot of current level size
            node = q.popleft()
            level.append(node.val)
            if node.left: q.append(node.left)
            if node.right: q.append(node.right)
        res.append(level)
    return res

复杂度：O(n) 时间；递归空间 O(h)，平衡树 O(log n)，退化成链时 O(n)（Python 需要 sys.setrecursionlimit 或改迭代）。

常见误区
  • Validate BST 只比较父子是错的：要传 (lo, hi) 上下界，或检查中序严格递增。
  • Max Path Sum：返回给父节点的只能是单边路径（max(L,R)+val），负贡献要截断为 0；"经过当前节点"的 L+R+val 只用来更新全局。
  • 层序遍历要用 for _ in range(len(q)) 固定当前层大小。
  • 深树递归超过 Python 默认递归上限（约 1000）。
Say it in English

For tree problems I start by defining exactly what my recursive function returns for a subtree. Here, dfs returns the best downward path sum starting at this node, which is what a parent can extend. Separately, at each node I compute the best path that bends through it, left plus right plus the node value, and update a global maximum. Negative contributions are clipped to zero because we can always choose not to extend into a subtree. It's O(n) time and O(h) stack space.

追问链
  1. How would you do this iteratively?
    思路
    用显式栈模拟。中序迭代：一路压左孩子，弹出访问，转向右孩子。后序迭代：前序"根右左"再反转，或者记录 last visited。
  2. LCA in a BST vs a general binary tree?
    思路
    BST：从根往下，两个值都小于当前就往左，都大于就往右，否则当前就是 LCA，O(h)。一般二叉树：后序，左右都找到则当前是 LCA，否则返回非空的那边，O(n)。
  3. How would you serialize a tree so that it can be reconstructed uniquely?
    思路
    前序 + 空节点标记（如 "#"）即可唯一重建；只有前序/中序之一（无空标记）不够，需要前序+中序两者（且值唯一）。

from collections import deque

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val, self.left, self.right = val, left, right

def build_tree(a):
    if not a or a[0] is None:
        return None
    root = TreeNode(a[0])
    q, i = deque([root]), 1
    while q and i < len(a):
        node = q.popleft()
        if i < len(a) and a[i] is not None:
            node.left = TreeNode(a[i]); q.append(node.left)
        i += 1
        if i < len(a) and a[i] is not None:
            node.right = TreeNode(a[i]); q.append(node.right)
        i += 1
    return root

def tree_to_list(root):
    out, q = [], deque([root])
    while q:
        n = q.popleft()
        if n is None:
            out.append(None); continue
        out.append(n.val); q.append(n.left); q.append(n.right)
    while out and out[-1] is None:
        out.pop()
    return out

LC 124 · Binary Tree Maximum Path Sum

求二叉树中任意一条路径（节点序列，至少一个节点，不必经过根）的最大节点值之和。

参考答案 · O(n) / O(h)
def max_path_sum(root):
    best = float('-inf')
    def gain(node):
        nonlocal best
        if not node:
            return 0
        L = max(gain(node.left), 0)      # drop negative branches
        R = max(gain(node.right), 0)
        best = max(best, node.val + L + R)
        return node.val + max(L, R)
    gain(root)
    return best

            if not node:

                return

            pre(node.left)
            pre(node.right)
        pre(root)

        it = iter(data.split(','))

            t = next(it)

            node.right = build()

        return build()

§9 · GRAPH TRAVERSAL图遍历：BFS / DFS（含网格）

★

图遍历：BFS / DFS（含网格）：识别、模板与代表题

一句话

DFS 用于"连通性 / 能否到达 / 枚举区域"，BFS 用于无权图最短路和"按步数扩散"。网格是隐式图：四个方向就是边。

DFS answers connectivity and region questions; BFS gives shortest paths in unweighted graphs and models step-by-step spreading. A grid is just an implicit graph with four-directional edges.

图题的第一步永远是建模：节点是什么？边是什么？有没有权重？然后选择遍历方式。

DFSBFS
数据结构递归栈 / 显式栈队列（deque）
擅长连通分量、环检测、回溯枚举、拓扑序（后序）无权最短路、层级、多源扩散
标记 visited 的时机进入节点时入队时（不是出队时，否则同一节点会被重复入队）

多源 BFS：把所有起点同时放进队列（距离 0），等价于加一个虚拟超级源点。Rotting Oranges、"每个格子到最近的 0 的距离"都是这个套路。

反向思考：Pacific Atlantic 中"从每个格子出发能否流到海"是 O((mn)²)；反过来"从海边逆流往高处走能到哪些格子"只需两次遍历 O(mn)。

识别信号

  • 网格 / 岛屿 / 迷宫
  • "最少步数 / 最短转换序列"（无权）→ BFS
  • "连通分量个数 / 能否到达"→ DFS 或并查集
  • "同时扩散 / 每分钟"→ 多源 BFS
  • 图的深拷贝 → DFS/BFS + 哈希表 old→new

通用模板

from collections import deque
DIRS = ((1, 0), (-1, 0), (0, 1), (0, -1))

def bfs_grid(grid, sources):
    """Multi-source BFS on a grid of '.'/'#'. Returns distance matrix (-1 = unreachable)."""
    m, n = len(grid), len(grid[0])
    dist = [[-1] * n for _ in range(m)]
    q = deque()
    for r, c in sources:
        dist[r][c] = 0
        q.append((r, c))
    while q:
        r, c = q.popleft()
        for dr, dc in DIRS:
            nr, nc = r + dr, c + dc
            if 0 <= nr < m and 0 <= nc < n and grid[nr][nc] != '#' and dist[nr][nc] == -1:
                dist[nr][nc] = dist[r][c] + 1      # mark when ENQUEUED
                q.append((nr, nc))
    return dist

def dfs_iter(adj, start):
    seen, stack = {start}, [start]
    while stack:
        u = stack.pop()
        for v in adj[u]:
            if v not in seen:
                seen.add(v)
                stack.append(v)
    return seen

复杂度：O(V + E)；网格 O(mn)。空间 O(V)。

常见误区
  • BFS 在出队时才标记 visited → 节点重复入队，最坏指数/平方级膨胀。
  • 递归 DFS 在 300×300 的网格上会超过 Python 递归上限 → 用 BFS 或显式栈，或 sys.setrecursionlimit。
  • 修改输入网格当 visited 很方便，但要问面试官是否允许修改输入。
  • Word Ladder 生成邻居：对每个位置尝试 26 个字母（O(L·26)），而不是两两比较所有单词（O(N²·L)）。
Say it in English

I'll model the grid as an implicit graph where each cell connects to its four neighbors. Since every move costs one step and we want the minimum number of minutes, BFS is the right tool, and because rotting starts from all rotten oranges simultaneously, I'll seed the queue with all of them at distance zero, which is a multi-source BFS. I'll mark cells as visited when I enqueue them to avoid duplicates. Total cost is O(m times n).

追问链
  1. When would you use bidirectional BFS?
    思路
    起点终点都已知、分支因子 b 大时：单向 \(O(b^d)\)，双向 \(O(b^{d/2})\)。每次扩展较小的那一侧，两侧 frontier 相交即找到。Word Ladder 可用。
  2. DFS vs Union-Find for counting connected components?
    思路
    静态图两者都是近似 O(V+E)。如果边是动态加入的（在线询问连通性，如 Number of Islands II），并查集更合适。

在由 "1"（陆地）和 "0"（水）组成的网格中，统计四连通陆地块（岛屿）的个数。

提示（关键洞察）

def num_islands(grid):
    if not grid:
        return 0
    m, n = len(grid), len(grid[0])
    seen = [[False] * n for _ in range(m)]
    count = 0
    for i in range(m):
        for j in range(n):
            if grid[i][j] == '1' and not seen[i][j]:
                count += 1
                seen[i][j] = True
                stack = [(i, j)]                 # iterative DFS: no recursion limit
                while stack:
                    r, c = stack.pop()
                    for nr, nc in ((r+1, c), (r-1, c), (r, c+1), (r, c-1)):
                        if 0 <= nr < m and 0 <= nc < n and grid[nr][nc] == '1' and not seen[nr][nc]:
                            seen[nr][nc] = True
                            stack.append((nr, nc))
    return count

class GNode:
    def __init__(self, val=0, neighbors=None):
        self.val = val
        self.neighbors = neighbors if neighbors is not None else []

def clone_graph(node):
    if not node:
        return None
    copies = {}
    def dfs(u):
        if u in copies:
            return copies[u]
        c = GNode(u.val)
        copies[u] = c                     # register BEFORE recursing (cycles)
        c.neighbors = [dfs(v) for v in u.neighbors]
        return c
    return dfs(node)

§10 · TOPOLOGICAL SORT & UNION-FIND拓扑排序 & 并查集

★

拓扑排序 & 并查集：识别、模板与代表题

一句话

有依赖关系（先修课、编译顺序）→ 拓扑排序（Kahn 入度 BFS，同时检测环）；动态合并集合 / 判断连通 / 无向图找环 → 并查集（路径压缩 + 按秩合并，近似 O(1)）。

Dependencies call for topological sort, where Kahn's in-degree BFS also detects cycles; dynamic grouping and connectivity call for union-find with path compression and union by rank, which is nearly constant time per operation.

拓扑排序只对 DAG 有定义。Kahn 算法：反复取出入度为 0 的点，删除它的出边；如果最终输出的点数 < n，说明有环。DFS 版本：后序的逆序就是拓扑序，用三色标记（0 未访问、1 在递归栈中、2 已完成）检测有向环——遇到颜色 1 的点就是回边。

并查集（Disjoint Set Union）：每个集合用一棵树表示，find 找根，union 把一棵树挂到另一棵下。

  • 路径压缩：find 时把沿途节点直接挂到根上。
  • 按秩/按大小合并：矮树挂到高树下。
  • 两者都用时，均摊复杂度为 \(O(\alpha(n))\)（反阿克曼函数，实际 ≤ 4），面试说"nearly constant amortized"。

无向图判环：加边 (u,v) 时若 find(u)==find(v)，这条边就形成环（Redundant Connection）。有向图判环不能用并查集，要用 DFS 三色或 Kahn。

识别信号

  • "先修 / 依赖 / 顺序 / 能否完成所有任务"→ 拓扑
  • "是否存在环"（有向 → 拓扑/三色；无向 → 并查集/DFS）
  • "合并账户 / 朋友圈 / 等价关系 / 连通分量数"→ 并查集
  • 边动态加入、在线连通查询

通用模板

from collections import deque
def topo_sort(n, edges):                 # edges: (u, v) means u -> v
    adj = [[] for _ in range(n)]
    indeg = [0] * n
    for u, v in edges:
        adj[u].append(v)
        indeg[v] += 1
    q = deque(i for i in range(n) if indeg[i] == 0)
    order = []
    while q:
        u = q.popleft()
        order.append(u)
        for v in adj[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)
    return order if len(order) == n else []   # [] means a cycle exists

class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.size = [1] * n
    def find(self, x):
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]   # path halving
            x = self.parent[x]
        return x
    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra == rb:
            return False                                  # already connected
        if self.size[ra] < self.size[rb]:
            ra, rb = rb, ra
        self.parent[rb] = ra                              # union by size
        self.size[ra] += self.size[rb]
        return True

复杂度：拓扑排序 O(V+E)；并查集 m 次操作 O(m·α(n))。

常见误区
  • 边的方向搞反：[a, b] 表示"修 a 之前要先修 b"，即 b → a。
  • 只做路径压缩、不按秩合并：均摊 O(log n)，一般也能过，但要知道理论界。
  • 递归版 find 在长链上会爆栈，用迭代（path halving）。
  • Accounts Merge 中，并查集的元素是邮箱（或账户下标），最后按根分组并排序。
Say it in English

This is a dependency problem, so I'll build a directed graph and run Kahn's algorithm: start with all nodes of in-degree zero, repeatedly pop one, append it to the order, and decrement the in-degree of its neighbors. If at the end the order contains fewer than n nodes, there must be a cycle, because nodes on a cycle never reach in-degree zero. It runs in O(V plus E).

追问链
  1. How do you find the lexicographically smallest topological order?
    思路
    把 Kahn 的队列换成最小堆，O((V+E) log V)。
  2. How many distinct topological orders are there? Is the order unique?
    思路
    唯一 ⇔ Kahn 过程中队列每时每刻最多只有一个元素（即存在哈密顿路径）。计数一般是 #P-hard，小规模用状态压缩 DP。

        color[u] = 2

            x = parent[x]

def accounts_merge(accounts):
    parent, owner = {}, {}
    def find(x):
        parent.setdefault(x, x)
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x
    def union(a, b):
        parent[find(a)] = find(b)

        for e in acc[1:]:
            owner[e] = name
            union(e, first)

        groups[find(e)].append(e)
    return [[owner[root]] + sorted(es) for root, es in groups.items()]

§11 · SHORTEST PATHS最短路：Dijkstra / Bellman-Ford

☆

最短路：Dijkstra / Bellman-Ford：识别、模板与代表题

一句话

非负权单源最短路 → Dijkstra（堆，O(E log V)）；有负权或"最多 k 条边"约束 → Bellman-Ford（按轮松弛，O(kE)）；无权 → BFS；0/1 权 → 0-1 BFS。

Use Dijkstra with a heap for non-negative weights, Bellman-Ford for negative weights or an edge-count limit, plain BFS for unweighted graphs, and 0-1 BFS for zero-or-one weights.

Dijkstra 的正确性依赖于"非负权"：从堆中弹出的距离最小的点，它的距离已经是最终值——因为任何其他路径都要经过某个距离更大的点，再加上非负边，不可能更短。有负边时这个论证失效。

懒删除（lazy deletion）：Python 的 heapq 没有 decrease-key，做法是直接 push 新的 (dist, node)，弹出时如果 d > dist[u] 就跳过（过期条目）。复杂度 O(E log E) = O(E log V)。

Bellman-Ford：对所有边松弛 V−1 轮；第 V 轮仍能松弛 ⇒ 存在负环。"最多 k 次中转"= 最多 k+1 条边 → 只做 k+1 轮，并且每轮要基于上一轮的距离副本松弛（否则一轮里可能连续走多条边）。

算法适用复杂度
BFS无权O(V+E)
0-1 BFS权为 0/1O(V+E)，deque 头插/尾插
Dijkstra非负权O((V+E) log V)
Bellman-Ford负权、边数限制、负环检测O(VE)
Floyd-Warshall全源，V 小（≤ 400）O(V³)

识别信号

  • 带权图 + "最短 / 最小代价 / 最早时间"
  • "最多经过 k 站"→ Bellman-Ford 或 (节点, 步数) 状态的 BFS/Dijkstra
  • 网格中移动代价不同 → Dijkstra on grid
  • "所有点到所有点"且点少 → Floyd

通用模板

import heapq
def dijkstra(n, adj, src):               # adj[u] = [(v, w), ...], w >= 0
    INF = float('inf')
    dist = [INF] * n
    dist[src] = 0
    pq = [(0, src)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]:
            continue                     # stale entry (lazy deletion)
        for v, w in adj[u]:
            nd = d + w
            if nd < dist[v]:
                dist[v] = nd
                heapq.heappush(pq, (nd, v))
    return dist

复杂度：Dijkstra O((V+E) log V)；Bellman-Ford O(V·E)（限 k 轮时 O(k·E)）。

常见误区
  • 不跳过过期堆条目，复杂度和正确性都可能出问题（重复松弛）。
  • Dijkstra 用于有负权的图——结果错误。
  • Cheapest Flights 中直接用 Dijkstra 按价格最短会错：便宜但站数多的路径可能挤掉站数少的路径；需要把 (节点, 已用站数) 作为状态，或用 Bellman-Ford。
  • Bellman-Ford 限轮数时没有用上一轮的副本。
Say it in English

All edge weights are non-negative, so I'll use Dijkstra with a min-heap keyed by tentative distance. Python's heapq doesn't support decrease-key, so I push duplicates and skip stale entries when the popped distance is larger than the recorded one. The invariant is that when a node is popped with its current best distance, that distance is final, because any alternative path would have to go through a node with a larger distance plus non-negative edges.

追问链
  1. Why does Dijkstra fail with negative edges?
    思路
    一个点被弹出（定稿）后，可能存在经过负边的更短路径到它，但 Dijkstra 不会再更新它。例：A→B 2, A→C 3, C→B −2；B 先被定稿为 2，实际最短为 1。
  2. How would you reconstruct the actual path?
    思路
    松弛成功时记录 prev[v] = u，最后从终点沿 prev 回溯再反转。
  3. What is A* and when is it better than Dijkstra?
    思路
    A* 用 f = g + h 作为堆的 key，h 是到终点距离的可采纳（不高估）启发式；h 一致（consistent）时每个点只需定稿一次。点对点查询、有好的几何启发式（曼哈顿/欧氏距离）时更快。

LC 743 · Network Delay Time

有向带权图中从节点 k 发出信号，求所有节点都收到信号所需的最短时间，若有节点收不到则返回 −1。

提示（关键洞察）

单源最短路 → Dijkstra；答案是所有最短距离的最大值。

参考答案 · O(E log V) / O(V+E)
import heapq
def network_delay_time(times, n, k):
    adj = [[] for _ in range(n + 1)]
    for u, v, w in times:
        adj[u].append((v, w))
    dist = [float('inf')] * (n + 1)
    dist[k] = 0
    pq = [(0, k)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]:
            continue
        for v, w in adj[u]:
            if d + w < dist[v]:
                dist[v] = d + w
                heapq.heappush(pq, (d + w, v))
    ans = max(dist[1:])
    return ans if ans < float('inf') else -1

复杂度：O(E log V) / O(V+E)

LC 787 · Cheapest Flights Within K Stops

给定航班（起点、终点、价格），求从 src 到 dst 最多经过 k 次中转的最便宜价格，不存在返回 −1。

提示（关键洞察）

Bellman-Ford 跑 k+1 轮，每轮基于上一轮的 副本 松弛，保证"第 i 轮结束时 = 最多 i 条边的最短距离"。

参考答案 · O(k·E) / O(V)
def find_cheapest_price(n, flights, src, dst, k):
    INF = float('inf')
    dist = [INF] * n
    dist[src] = 0
    for _ in range(k + 1):                # at most k+1 edges
        new = dist[:]                     # relax from previous round only
        for u, v, w in flights:
            if dist[u] + w < new[v]:
                new[v] = dist[u] + w
        dist = new
    return dist[dst] if dist[dst] < INF else -1

复杂度：O(k·E) / O(V)

LC 1631 · Path With Minimum Effort

在高度网格上从左上走到右下，路径的"代价"是相邻两步高度差绝对值的最大值，求最小代价。

提示（关键洞察）

Dijkstra 的变体：路径代价是 max 而不是 sum（仍满足"扩展不会变小"的单调性）。也可以二分答案 + BFS。

参考答案 · O(mn log(mn)) / O(mn)
import heapq
def minimum_effort_path(h):
    m, n = len(h), len(h[0])
    best = [[float('inf')] * n for _ in range(m)]
    best[0][0] = 0
    pq = [(0, 0, 0)]
    while pq:
        e, r, c = heapq.heappop(pq)
        if (r, c) == (m - 1, n - 1):
            return e
        if e > best[r][c]:
            continue
        for nr, nc in ((r+1, c), (r-1, c), (r, c+1), (r, c-1)):
            if 0 <= nr < m and 0 <= nc < n:
                ne = max(e, abs(h[nr][nc] - h[r][c]))
                if ne < best[nr][nc]:
                    best[nr][nc] = ne
                    heapq.heappush(pq, (ne, nr, nc))
    return 0

复杂度：O(mn log(mn)) / O(mn)

§12 · HEAPS堆 / 优先队列

★

堆 / 优先队列：识别、模板与代表题

一句话

"第 k 大 / 前 k 个 / 动态取最值"→ 堆。求最大的 k 个用大小为 k 的最小堆（O(n log k)）；数据流中位数用两个堆。

Heaps solve top-k and running-extreme problems: keep a size-k min-heap for the k largest in O(n log k), and use two heaps for a streaming median.

Python 的 heapq 是最小堆，作用在普通 list 上：heappush、heappop、heapify（O(n)）、heapreplace、nlargest/nsmallest。最大堆：存负数。复合元素用 tuple 并加 tiebreak。

为什么"前 k 大"用最小堆？堆里维护"目前见过的最大的 k 个"，堆顶是这 k 个中最小的——新元素只要比堆顶大就替换掉堆顶。每次操作 O(log k)，总共 O(n log k)，空间 O(k)，适合数据流。

替代方案：Quickselect 平均 O(n)、最坏 O(n²)（随机化 pivot 可避免大多数最坏情况），但需要全部数据在内存中且会修改数组。

heapify 为什么是 O(n)？自底向上下沉：高度为 h 的节点约有 \(n/2^{h+1}\) 个，每个下沉 O(h)，\(\sum_h \frac{n}{2^{h+1}} h = O(n)\)。

识别信号

  • "第 k 大 / 最小的 k 个 / 前 k 高频"
  • "数据流 / 实时"取最值或中位数
  • 多路归并（k 个有序序列）
  • 贪心中"每次选当前最好的"（任务调度、会议室）

通用模板

import heapq
def k_largest(nums, k):
    h = []
    for x in nums:
        if len(h) < k:
            heapq.heappush(h, x)
        elif x > h[0]:
            heapq.heapreplace(h, x)      # pop smallest then push x, one O(log k) op
    return h                             # h[0] is the k-th largest

# max-heap of tuples with tie-break counter
import itertools
counter = itertools.count()
def push_max(h, priority, item):
    heapq.heappush(h, (-priority, next(counter), item))

复杂度：push/pop O(log n)，peek O(1)，heapify O(n)；top-k O(n log k)。

常见误区
  • 用最大堆弹 k 次求第 k 大是 O(n + k log n)，也可以，但要会解释和最小堆版本的区别（流式场景下最小堆更好）。
  • tuple 第一项相等时会比较第二项；如果第二项是不可比较的对象（dict、ListNode）会抛 TypeError → 加计数器。
  • 两个堆求中位数时，忘记平衡大小（保持 len(lo) == len(hi) 或 len(hi)+1）。
  • Task Scheduler 有 O(n) 的公式解，面试官可能追问。
Say it in English

Since I only need the k largest elements, I'll keep a min-heap of size k. The root is the smallest of the current top k, so any new element larger than the root replaces it. That's O(n log k) time and O(k) memory, and it works on a stream. If the whole array is in memory and I want average linear time, I could also mention quickselect, with the caveat of a quadratic worst case.

求未排序数组中第 k 大的元素（按排序后的位置，不是去重后的第 k 个）。

提示（关键洞察）

参考答案 · 堆 O(n log k) / O(k)；quickselect 期望 O(n)
import heapq, random
def find_kth_largest(nums, k):
    h = nums[:k]
    heapq.heapify(h)
    for x in nums[k:]:
        if x > h[0]:
            heapq.heapreplace(h, x)
    return h[0]

def quickselect(nums, k):          # k-th largest, expected O(n)
    pivot = random.choice(nums)
    big = [x for x in nums if x > pivot]
    eq = [x for x in nums if x == pivot]
    small = [x for x in nums if x < pivot]
    if k <= len(big):
        return quickselect(big, k)
    if k <= len(big) + len(eq):
        return pivot
    return quickselect(small, k - len(big) - len(eq))

复杂度：堆 O(n log k) / O(k)；quickselect 期望 O(n)

LC 295 · Find Median from Data Stream

设计数据结构支持不断加入数字和随时查询当前中位数。

提示（关键洞察）

lo：最大堆（存负数）放较小的一半；hi：最小堆放较大的一半。保持 len(lo) == len(hi) 或 len(lo) == len(hi) + 1。

参考答案 · add O(log n)，find O(1) / O(n)
import heapq
class MedianFinder:
    def __init__(self):
        self.lo = []    # max-heap via negation: smaller half
        self.hi = []    # min-heap: larger half
    def addNum(self, x):
        heapq.heappush(self.lo, -x)
        heapq.heappush(self.hi, -heapq.heappop(self.lo))   # move lo's max to hi
        if len(self.hi) > len(self.lo):
            heapq.heappush(self.lo, -heapq.heappop(self.hi))
    def findMedian(self):
        if len(self.lo) > len(self.hi):
            return float(-self.lo[0])
        return (-self.lo[0] + self.hi[0]) / 2

复杂度：add O(log n)，find O(1) / O(n)

LC 621 · Task Scheduler

给定任务列表（字母）和冷却时间 n（相同任务之间至少间隔 n 个时间单位），求完成所有任务的最少时间单位数（可以空闲）。

提示（关键洞察）

公式：设最高频次为 f，达到 f 的任务有 c 个，答案 = max(len(tasks), (f−1)(n+1) + c)。直觉：最高频任务排成 f 个"框架"，每框长 n+1。也可以用堆模拟。

参考答案 · O(T) / O(26)
from collections import Counter
def least_interval(tasks, n):
    cnt = Counter(tasks)
    f = max(cnt.values())
    c = sum(1 for v in cnt.values() if v == f)
    return max(len(tasks), (f - 1) * (n + 1) + c)

import heapq
from collections import deque
def least_interval_sim(tasks, n):          # heap simulation, O(T log 26)
    h = [-v for v in Counter(tasks).values()]
    heapq.heapify(h)
    cool = deque()                         # (time available, -remaining)
    t = 0
    while h or cool:
        t += 1
        if h:
            r = heapq.heappop(h) + 1       # run one unit of the most frequent task
            if r:
                cool.append((t + n, r))
        if cool and cool[0][0] == t:
            heapq.heappush(h, cool.popleft()[1])
    return t

复杂度：O(T) / O(26)

def k_closest(points, k):
    h = []                                   # (-dist2, x, y): max-heap of size k
    for x, y in points:
        d = x * x + y * y
        if len(h) < k:
            heapq.heappush(h, (-d, x, y))
        elif -d > h[0][0]:                   # closer than the farthest kept
            heapq.heapreplace(h, (-d, x, y))
    return [[x, y] for _, x, y in h]

§13 · BACKTRACKING回溯

★

回溯：识别、模板与代表题

一句话

枚举所有解（子集、排列、组合、棋盘放置）：选择 → 递归 → 撤销。复杂度通常是指数级，关键是剪枝和避免重复。

Backtracking enumerates all solutions by choosing, recursing, and undoing the choice; complexity is exponential, so pruning and duplicate avoidance are what matter.

回溯 = 在一棵"决策树"上做 DFS。每个节点是一个部分解（path），每条边是一个选择。

问题决策解的个数去重关键
子集 Subsets每个元素选/不选；或"从 start 开始选下一个"\(2^n\)用 start 保证只往后选
组合 Combinations / Combination Sum从 start 开始选，可重复则下一层仍从 i 开始—排序 + 剪枝 if x > remain: break
排列 Permutations每个位置从未用过的元素中选\(n!\)used 数组；有重复时 if i>0 and a[i]==a[i-1] and not used[i-1]: continue
棋盘 N-Queens / Sudoku每行放哪一列—用 set 记录占用的列和两条对角线（r−c, r+c）

复杂度怎么说：子集 \(O(n\cdot 2^n)\)（\(2^n\) 个解、每个复制 O(n)）；排列 \(O(n\cdot n!)\)；Word Search \(O(mn\cdot 4\cdot 3^{L-1})\)（第一步 4 个方向，之后不能回头只剩 3 个）。

识别信号

  • "所有可能的 / 列出全部"（all combinations / permutations / subsets）
  • n 很小（≤ 15–20）
  • 约束满足问题（数独、N 皇后、单词搜索）
  • 只问"个数"或"最优值"时，先想能不能 DP（回溯会超时）

通用模板

def backtrack_template(nums):
    res, path = [], []
    def bt(start):
        res.append(path[:])              # record a COPY (path is mutated later)
        for i in range(start, len(nums)):
            if i > start and nums[i] == nums[i - 1]:
                continue                 # skip duplicates at the same tree level (nums sorted)
            path.append(nums[i])         # choose
            bt(i + 1)                    # explore (i, not i+1, if reuse allowed)
            path.pop()                   # un-choose
    nums.sort()
    bt(0)
    return res

复杂度：指数级：子集 O(n·2^n)，排列 O(n·n!)。空间 O(n) 递归深度（不计输出）。

常见误区
  • res.append(path) 而不是 path[:]——最后所有结果都是同一个（空）list。
  • 忘记撤销（pop / 恢复 visited 标记）。
  • 去重条件写在错误的层级：同层去重用 i > start，不是 i > 0。
  • Word Search 中把格子标记为 "#" 后，返回前必须恢复原字符。
Say it in English

Since we need to list all valid combinations, I'll use backtracking: build a partial solution, recurse, then undo the last choice. To avoid generating the same combination in different orders, each level only picks elements at or after a start index. I'll sort the candidates first so I can prune: once a candidate exceeds the remaining target, every later one does too, so I can break. The worst case is still exponential, which is inherent since the output itself can be exponential.

        for i in range(start, len(nums)):
            path.append(nums[i])
            bt(i + 1)
            path.pop()
    bt(0)
    return res

def subsets_bits(nums):
    n = len(nums)
    return [[nums[i] for i in range(n) if mask >> i & 1] for mask in range(1 << n)]

def permute(nums):
    res, path = [], []
    used = [False] * len(nums)
    def bt():
        if len(path) == len(nums):
            res.append(path[:])
            return
        for i, x in enumerate(nums):
            if used[i]:
                continue
            used[i] = True
            path.append(x)
            bt()
            path.pop()
            used[i] = False
    bt()
    return res

def solve_n_queens(n):

    used_c, used_d1, used_d2 = set(), set(), set()
    def bt(r):
        if r == n:
            res.append(['.' * c + 'Q' + '.' * (n - c - 1) for c in cols])

    bt(0)

LC 79 · Word Search

提示（关键洞察）

参考答案 · O(mn·3^L) / O(L)
def exist(board, word):
    m, n = len(board), len(board[0])
    def dfs(r, c, k):
        if k == len(word):
            return True
        if not (0 <= r < m and 0 <= c < n) or board[r][c] != word[k]:
            return False
        tmp, board[r][c] = board[r][c], '#'          # mark visited
        found = (dfs(r+1, c, k+1) or dfs(r-1, c, k+1) or
                 dfs(r, c+1, k+1) or dfs(r, c-1, k+1))
        board[r][c] = tmp                            # restore
        return found
    return any(dfs(i, j, 0) for i in range(m) for j in range(n))

复杂度：O(mn·3^L) / O(L)

§14 · DYNAMIC PROGRAMMING动态规划

★

动态规划：识别、模板与代表题

一句话

DP = 有重叠子问题的递归 + 记忆化。四步：定义状态 → 写转移 → 定 base case → 定计算顺序；先写 @cache 递归版，再改成表格并压缩空间。

Dynamic programming is recursion with overlapping subproblems plus memoization: define the state, write the transition, set base cases, choose an evaluation order, then optionally compress space.

DP 是面试里最怕的题型，但套路很固定。推荐流程（面试时可以边说边做）：

  1. 先写暴力递归：f(i) = "从第 i 个开始（或前 i 个）的最优值"。把问题拆成"最后一步做什么选择"。
  2. 发现重叠子问题，加 @functools.cache → 复杂度 = 状态数 × 每个状态的转移成本。
  3. 改写成自底向上表格（避免递归深度问题），确定填表顺序。
  4. 空间压缩：如果 dp[i] 只依赖 dp[i−1]、dp[i−2]，用几个变量；二维只依赖上一行时用一维滚动数组。
类别状态代表题
一维线性dp[i] = 前 i 个的答案Climbing Stairs、House Robber、Word Break、LIS
背包dp[容量]，0/1 背包倒序、完全背包正序Coin Change、Partition Equal Subset Sum
双序列dp[i][j] = a 前 i 个与 b 前 j 个LCS、Edit Distance
网格dp[i][j] 来自上和左Unique Paths、Min Path Sum
区间dp[l][r]，按长度递增Longest Palindromic Subsequence、Burst Balloons
状态机dp[i][持有/不持有]买卖股票系列
直觉DP 和 RL 的 Bellman 方程是同一个思想：最优子结构 \(V(s) = \max_a [r(s,a) + V(s')]\)。面试时如果你说"this is essentially a Bellman recursion over states i"，对 RS 面试官很自然。

识别信号

  • "最多 / 最少 / 最长 / 方案数 / 能否"
  • 暴力递归有重复调用
  • 选择会影响后续（贪心不对）
  • 输入规模 n ≤ 10^3–10^4（O(n²) 可行）或背包容量不大

通用模板

from functools import cache
def dp_top_down(nums):
    @cache
    def f(i):                       # best answer for suffix nums[i:]
        if i >= len(nums):
            return 0                # base case
        return max(f(i + 1),                # skip i
                   nums[i] + f(i + 2))      # take i
    return f(0)

def dp_bottom_up(nums):
    n = len(nums)
    dp = [0] * (n + 2)
    for i in range(n - 1, -1, -1):  # order: dependencies (i+1, i+2) computed first
        dp[i] = max(dp[i + 1], nums[i] + dp[i + 2])
    return dp[0]

复杂度：时间 = 状态数 × 转移成本；空间 = 状态数（可压缩）。

常见误区
  • 0/1 背包一维数组必须倒序遍历容量（否则同一物品被用多次）；完全背包正序。
  • 方案数类：外层物品、内层容量 = 组合数；外层容量、内层物品 = 排列数。
  • @cache 的参数必须可哈希（list 不行，用 tuple 或下标）；递归深度 > 1000 时要改表格或调 recursionlimit。
  • Coin Change 不可达时要返回 −1：初始化为 inf 而不是 0。
Say it in English

Let me first write the recursive formulation. Define f(i) as the best we can do on the suffix starting at i. At each step there are two choices, so f(i) is the max of skipping i or taking i and jumping to i plus 2. The naive recursion is exponential because subproblems repeat, so I'll memoize it, which gives O(n) states with O(1) work each. Then I can convert it to a bottom-up loop and, since each state only depends on the next two, reduce the space to two variables.

追问链
  1. How do you recover the actual solution, not just the optimal value?
    思路
    保存 choice 数组，或者在填完表后从终点回溯：检查 dp[i] 是由哪个转移得到的。例如 LCS 从 (m,n) 回溯：字符相等走对角线，否则走较大的一边。
  2. Greedy vs DP: how do you know greedy works?
    思路
    需要证明贪心选择性质（exchange argument）：任何最优解都可以被改造成包含贪心选择的最优解。Coin Change 在一般币值下贪心不对（[1,3,4] 凑 6：贪心 4+1+1，最优 3+3）。
  3. What is the connection between DP and shortest paths?
    思路
    DP 的状态和转移构成一个 DAG，DP 就是在 DAG 上按拓扑序求最短/最长路。有环时不能直接 DP，需要 Bellman-Ford / Dijkstra。

LC 322 · Coin Change

给定硬币面额（每种无限个），求凑出金额 amount 所需的最少硬币数，凑不出返回 −1。

提示（关键洞察）

def coin_change(coins, amount):
    INF = float('inf')
    dp = [0] + [INF] * amount
    for a in range(1, amount + 1):
        for c in coins:
            if c <= a and dp[a - c] + 1 < dp[a]:
                dp[a] = dp[a - c] + 1
    return dp[amount] if dp[amount] < INF else -1

def coin_change_ways(coins, amount):      # LC 518: number of combinations
    dp = [1] + [0] * amount
    for c in coins:                       # coins outer -> combinations (order ignored)
        for a in range(c, amount + 1):    # forward: unbounded supply
            dp[a] += dp[a - c]
    return dp[amount]

复杂度：O(amount · #coins) / O(amount)

import bisect
def length_of_lis(nums):
    tails = []
    for x in nums:
        i = bisect.bisect_left(tails, x)   # bisect_right for non-decreasing
        if i == len(tails):
            tails.append(x)
        else:
            tails[i] = x                   # smaller tail for length i+1
    return len(tails)

def length_of_lis_n2(nums):
    dp = [1] * len(nums)
    for i in range(len(nums)):
        for j in range(i):
            if nums[j] < nums[i]:
                dp[i] = max(dp[i], dp[j] + 1)
    return max(dp, default=0)

LC 1143 · Longest Common Subsequence

参考答案 · O(mn) / O(mn)，可压到 O(min(m,n))
def lcs(a, b):
    m, n = len(a), len(b)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if a[i - 1] == b[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
    return dp[m][n]

复杂度：O(mn) / O(mn)，可压到 O(min(m,n))

LC 72 · Edit Distance

求把字符串 a 变成 b 的最少操作数（插入、删除、替换一个字符）。

提示（关键洞察）

dp[i][j] = a[:i] → b[:j] 的最少操作。相等：dp[i−1][j−1]；否则 1 + min(删 dp[i−1][j], 插 dp[i][j−1], 替换 dp[i−1][j−1])。边界 dp[i][0]=i, dp[0][j]=j。

参考答案 · O(mn) / O(n)
def min_distance(a, b):
    m, n = len(a), len(b)
    prev = list(range(n + 1))                # row i-1
    for i in range(1, m + 1):
        cur = [i] + [0] * n
        for j in range(1, n + 1):
            if a[i - 1] == b[j - 1]:
                cur[j] = prev[j - 1]
            else:
                cur[j] = 1 + min(prev[j],        # delete a[i-1]
                                 cur[j - 1],     # insert b[j-1]
                                 prev[j - 1])    # replace
        prev = cur
    return prev[n]

复杂度：O(mn) / O(n)

LC 416 · Partition Equal Subset Sum

参考答案 · O(n · sum) / O(sum)
def can_partition(nums):
    total = sum(nums)
    if total % 2:
        return False
    target = total // 2
    dp = [True] + [False] * target
    for x in nums:
        for s in range(target, x - 1, -1):   # reverse: each item used at most once
            dp[s] = dp[s] or dp[s - x]
    return dp[target]

def can_partition_bits(nums):
    total = sum(nums)
    if total % 2:
        return False
    bits = 1                                 # bit s set <=> sum s reachable
    for x in nums:
        bits |= bits << x
    return bool(bits >> (total // 2) & 1)

复杂度：O(n · sum) / O(sum)

    words = set(word_dict)
    L = max(map(len, words), default=0)
    dp = [True] + [False] * len(s)
    for i in range(1, len(s) + 1):
        for j in range(max(0, i - L), i):
            if dp[j] and s[j:i] in words:
                dp[i] = True
                break
    return dp[-1]

参考答案 · O(mn) / O(n)
def unique_paths(m, n):
    row = [1] * n
    for _ in range(1, m):
        for j in range(1, n):
            row[j] += row[j - 1]      # row[j] (from above) + row[j-1] (from left)
    return row[-1]

LC 5 · Longest Palindromic Substring

求字符串中最长的回文子串。（题单里属于 §16 字符串类，因为经典解法与 DP 同源，放在这里讲。）

提示（关键洞察）

中心扩展：2n−1 个中心（字符本身和字符之间），每个向两边扩展。O(n²) 时间 O(1) 空间，比 dp[i][j] 表格更简洁。Manacher 可做到 O(n)（加分项）。

参考答案 · O(n²) / O(1)
def longest_palindrome(s):
    if not s:
        return ""
    best_l, best_r = 0, 0
    def expand(l, r):
        while l >= 0 and r < len(s) and s[l] == s[r]:
            l -= 1
            r += 1
        return l + 1, r - 1                 # last valid window
    for i in range(len(s)):
        for l, r in (expand(i, i), expand(i, i + 1)):   # odd, even centers
            if r - l > best_r - best_l:
                best_l, best_r = l, r
    return s[best_l:best_r + 1]

复杂度：O(n²) / O(1)

§15 · INTERVALS & GREEDY区间 & 贪心

★

区间 & 贪心：识别、模板与代表题

一句话

区间题第一步几乎总是排序：合并按起点排，"选最多不重叠"按终点排。贪心必须能用交换论证（exchange argument）说明为什么局部最优不会错。

Interval problems almost always start by sorting: by start for merging, by end for selecting the most non-overlapping intervals; a greedy choice must be justified with an exchange argument.

区间题的三种排序：

  • 按起点排序 → 合并重叠区间、插入区间：维护"当前合并块"的右端点。
  • 按终点排序 → 最多不重叠区间数 / 最少删除数 / 最少箭数：每次选结束最早的，给后面留最多空间（经典活动选择问题）。
  • 起点和终点拆成事件排序（sweep line）→ 最多同时重叠数（会议室 II）：+1 / −1 扫描，或用最小堆存结束时间。

活动选择贪心的交换论证：设最优解的第一个区间是 O₁，贪心选的是结束最早的 G₁，end(G₁) ≤ end(O₁)。把 O₁ 换成 G₁，不会和后面的区间冲突（G₁ 结束得更早），数量不变——所以存在一个包含贪心选择的最优解，归纳即可。

其他贪心：Jump Game（维护最远可达）、Gas Station（总和 ≥ 0 则有解，从亏损点之后重新开始）、Partition Labels（每个字母最后出现位置）。

识别信号

  • 输入是 [start, end] 对
  • "合并 / 插入 / 最少删除 / 最少会议室 / 最多参加"
  • "能否到达 / 最少跳跃次数"
  • 局部最优选择看起来显然，并且能写出交换论证

通用模板

def merge_intervals(iv):
    iv.sort(key=lambda x: x[0])          # sort by start
    out = []
    for s, e in iv:
        if out and s <= out[-1][1]:      # overlaps current block
            out[-1][1] = max(out[-1][1], e)
        else:
            out.append([s, e])
    return out

def max_non_overlapping(iv):
    iv.sort(key=lambda x: x[1])          # sort by END
    count, last_end = 0, float('-inf')
    for s, e in iv:
        if s >= last_end:                # compatible (touching allowed)
            count += 1
            last_end = e
    return count

复杂度：排序主导 O(n log n)，扫描 O(n)。

常见误区
  • 合并时忘记 max：[1,10],[2,3] 合并后右端点应为 10 而不是 3。
  • "端点相接算不算重叠"要问清楚（[1,2] 和 [2,3]）——不同题定义不同。
  • 按起点排序做"最少删除"也能做但更绕（重叠时保留结束早的）；按终点排序最直接。
  • Python 的 sort 会修改输入；需要保留原数组时用 sorted。
Say it in English

I'll sort the intervals by start time, then sweep through them while maintaining the last merged interval. If the next interval starts before the current one ends, they overlap, so I extend the end to the max of the two ends; otherwise I start a new block. Sorting dominates, so it's O(n log n). I should confirm whether touching intervals like one-two and two-three count as overlapping.

LC 57 · Insert Interval

在一组已按起点排序且互不重叠的区间中插入一个新区间，必要时合并，保持有序不重叠。

提示（关键洞察）

三段：完全在新区间左边的直接加入；和新区间重叠的合并进新区间；完全在右边的直接加入。O(n)，无需排序。

参考答案 · O(n) / O(n)
def insert(intervals, new):
    s, e = new
    left, right = [], []
    for a, b in intervals:
        if b < s:
            left.append([a, b])
        elif a > e:
            right.append([a, b])
        else:                            # overlap: absorb into new interval
            s, e = min(s, a), max(e, b)
    return left + [[s, e]] + right

参考答案 · O(n log n) / O(n)
import heapq
def min_meeting_rooms(intervals):
    ends = []
    for s, e in sorted(intervals):
        if ends and ends[0] <= s:        # earliest-ending room is free
            heapq.heapreplace(ends, e)
        else:
            heapq.heappush(ends, e)
    return len(ends)

def min_meeting_rooms_sweep(intervals):
    starts = sorted(s for s, _ in intervals)
    ends = sorted(e for _, e in intervals)
    rooms = best = j = 0
    for s in starts:
        while j < len(ends) and ends[j] <= s:
            rooms -= 1
            j += 1
        rooms += 1
        best = max(best, rooms)
    return best

§16 · TRIE & STRINGSTrie & 字符串

☆

Trie & 字符串：识别、模板与代表题

一句话

Trie（前缀树）把一组单词按前缀共享存储，插入/查询 O(L)；用于前缀查询、自动补全、多模式匹配（Word Search II）。和 LLM 的 tokenizer、constrained decoding 直接相关。

A trie stores words by shared prefixes so insert and lookup are O(L); it powers prefix queries, autocomplete, and multi-pattern search, and it shows up in tokenizers and constrained decoding.

Trie 节点 = children: dict[str, Node] + is_end: bool。Python 里最简写法是嵌套 dict：node = node.setdefault(ch, {})，用特殊 key（如 '$'）标记单词结尾。

和 RS 面试的联系：BPE/WordPiece tokenizer 的最长匹配、grammar-constrained / JSON-constrained decoding（在每一步把不合法 token 的 logit 设为 −inf，合法 token 集合常用 trie 或自动机维护）、beam search 中的前缀去重。面试官问"如何保证模型只输出列表中的实体名"时，"在实体名 trie 上做 constrained decoding"是一个好答案。

字符串其他常见技巧：回文中心扩展、KMP 前缀函数（O(n+m) 子串匹配）、Rabin-Karp 滚动哈希、"字符计数 → 26 维数组"。

识别信号

  • "前缀 / startsWith / 自动补全"
  • 在网格或文本中同时查找多个单词
  • 字典 + 逐字符匹配，需要提前剪枝
  • 异或最大值类问题（二进制 trie，加分）

通用模板

class Trie:
    def __init__(self):
        self.root = {}
    def insert(self, word):
        node = self.root
        for ch in word:
            node = node.setdefault(ch, {})
        node['$'] = True                 # end-of-word marker
    def _walk(self, s):
        node = self.root
        for ch in s:
            if ch not in node:
                return None
            node = node[ch]
        return node
    def search(self, word):
        node = self._walk(word)
        return node is not None and '$' in node
    def startsWith(self, prefix):
        return self._walk(prefix) is not None

复杂度：插入/查询 O(L)；空间 O(总字符数 × 每节点开销)。

常见误区
  • 把"前缀存在"和"单词存在"混为一谈（search 需要检查结束标记）。
  • 用 '$' 作结束标记时要保证单词里不会出现 $（或者用 class 节点 + is_end 字段）。
  • Word Search II 对每个单词单独跑 Word Search 会超时；应该把所有单词建 trie，一次 DFS 同时匹配，并在找到后删除叶子剪枝。
  • Python 字符串不可变，循环里 s += ch 是 O(n²)；用 list 收集再 ''.join。
Say it in English

I'll build a trie over all the dictionary words so I can walk the board once and match every word simultaneously. During DFS, I only continue in directions where the current prefix exists in the trie, which prunes most of the search. When I reach a node marking the end of a word, I record it and remove the marker so it's not reported twice; I can also prune empty leaves to speed up later searches. This is much faster than running a separate word search per word.

class TrieNode:
    __slots__ = ('children', 'is_end')
    def __init__(self):
        self.children = {}
        self.is_end = False

class Trie2:
    def __init__(self):
        self.root = TrieNode()
    def insert(self, word):
        node = self.root
        for ch in word:
            if ch not in node.children:
                node.children[ch] = TrieNode()
            node = node.children[ch]
        node.is_end = True
    def _find(self, s):
        node = self.root
        for ch in s:
            node = node.children.get(ch)
            if node is None:
                return None
        return node
    def search(self, word):
        node = self._find(word)
        return bool(node and node.is_end)
    def startsWith(self, prefix):
        return self._find(prefix) is not None

LC 211 · Design Add and Search Words Data Structure

设计数据结构支持添加单词和查询单词，查询串中 "." 可以匹配任意一个字母。

提示（关键洞察）

Trie + DFS：遇到 "." 时遍历所有孩子。

参考答案 · add O(L)；search 最坏 O(26^L)
class WordDictionary:
    def __init__(self):
        self.root = {}
    def addWord(self, word):
        node = self.root
        for ch in word:
            node = node.setdefault(ch, {})
        node['$'] = True
    def search(self, word):
        def dfs(node, i):
            if i == len(word):
                return '$' in node
            ch = word[i]
            if ch == '.':
                return any(dfs(child, i + 1) for k, child in node.items() if k != '$')
            return ch in node and dfs(node[ch], i + 1)
        return dfs(self.root, 0)

LC 212 · Word Search II

给定字母网格和单词列表，返回所有能在网格中（相邻格子、不重复使用）找到的单词。

提示（关键洞察）

所有单词建 trie，节点存完整单词；从每个格子 DFS 沿 trie 走；找到后清除单词标记，并在回溯时删除空子节点剪枝。

参考答案 · O(mn·3^L) 最坏 / O(总字符数)
def find_words(board, words):
    root = {}
    for w in words:
        node = root
        for ch in w:
            node = node.setdefault(ch, {})
        node['$'] = w                          # store the word itself
    m, n = len(board), len(board[0])
    found = []
    def dfs(r, c, parent):
        ch = board[r][c]
        node = parent[ch]
        if '$' in node:
            found.append(node.pop('$'))        # report once
        board[r][c] = '#'
        for nr, nc in ((r+1, c), (r-1, c), (r, c+1), (r, c-1)):
            if 0 <= nr < m and 0 <= nc < n and board[nr][nc] in node:
                dfs(nr, nc, node)
        board[r][c] = ch
        if not node:
            parent.pop(ch)                     # prune exhausted branch
    for i in range(m):
        for j in range(n):
            if board[i][j] in root:
                dfs(i, j, root)
    return found

复杂度：O(mn·3^L) 最坏 / O(总字符数)

LC 28 · Find the Index of the First Occurrence in a String

返回 needle 在 haystack 中第一次出现的下标，不存在返回 −1。

提示（关键洞察）

面试中可以说 str.find，但若要求手写线性算法：KMP。前缀函数 pi[i] = p[:i+1] 的最长真前缀且同时为后缀的长度。

参考答案 · O(n+m) / O(m)
def str_str(hay, needle):
    if not needle:
        return 0
    pi = [0] * len(needle)                  # prefix function
    k = 0
    for i in range(1, len(needle)):
        while k and needle[i] != needle[k]:
            k = pi[k - 1]
        if needle[i] == needle[k]:
            k += 1
        pi[i] = k
    k = 0
    for i, ch in enumerate(hay):
        while k and ch != needle[k]:
            k = pi[k - 1]                   # fall back, never move i backwards
        if ch == needle[k]:
            k += 1
        if k == len(needle):
            return i - k + 1
    return -1

复杂度：O(n+m) / O(m)

§17 · BIT MANIPULATION & MATH位运算 & 数学

○

位运算 & 数学：识别、模板与代表题

一句话

记住几个恒等式：x ^ x = 0、x & (x-1) 去掉最低位的 1、x & -x 取最低位的 1；快速幂 O(log n)。

Know a few identities: x xor x is zero, x and x minus one clears the lowest set bit, x and negative x isolates it; fast exponentiation runs in O(log n).

操作写法用途
异或消去a ^ a = 0, a ^ 0 = a找唯一出现一次的数、交换
去掉最低位 1x & (x - 1)数 1 的个数（Kernighan）、判断 2 的幂 x > 0 and x & (x-1) == 0
取最低位 1x & -xFenwick tree、Single Number III 分组
第 i 位x >> i & 1，置位 x | 1 << i位掩码枚举子集、状态压缩 DP
popcountbin(x).count('1') / x.bit_count()（3.10+）

Python 的坑：int 是任意精度，负数在概念上有无限个前导 1，~x == -x-1。模拟 32 位时需要 & 0xFFFFFFFF 并手动转回有符号数。

快速幂：\(x^n\) 按 n 的二进制展开，\(x^{13} = x^8 \cdot x^4 \cdot x^1\)，每步平方底数，O(log n)。同样的思想用于矩阵快速幂（O(log n) 求斐波那契）、模幂 pow(a, b, m)。

识别信号

  • "只出现一次 / 缺失的数"且要求 O(1) 空间
  • "2 的幂 / 1 的个数 / 二进制"
  • n ≤ 20 的子集状态（位掩码）
  • 大指数 / 取模

通用模板

def popcount(x):                 # Brian Kernighan: one iteration per set bit
    c = 0
    while x:
        x &= x - 1
        c += 1
    return c

def fast_pow(x, n):              # x ** n for integer n (can be negative)
    if n < 0:
        x, n = 1 / x, -n
    res = 1
    while n:
        if n & 1:
            res *= x
        x *= x
        n >>= 1
    return res

复杂度：位运算 O(1)/O(位数)；快速幂 O(log n)。

常见误区
  • Python 中对负数做右移/与运算的结果和 C 的 32 位语义不同。
  • 运算符优先级：x & 1 == 0 在 Python 中是 x & (1 == 0)！要写 (x & 1) == 0。（C 中同样有这个坑。）
  • Pow(x, n) 的 n 为负数和 n = −2³¹（其他语言取反溢出）。
  • 浮点比较用误差容忍，不要用 ==。
Say it in English

The key observation is that XOR is associative and commutative, and any number XORed with itself is zero. So if I XOR all the elements together, every number that appears twice cancels out and only the single number remains. That's O(n) time and O(1) extra space, which beats the hash-set approach on memory.

    思路

  2. How do you compute Fibonacci(n) mod p for n = 10^18?
    思路
    矩阵快速幂：[[1,1],[1,0]]^n，O(log n) 次 2×2 矩阵乘法。

LC 338 · Counting Bits

§6 二分查找 & 二分答案二分的本质不是"有序数组找值"，而是在单调的布尔函数上找第一个 True。固定用 [lo, hi) 半开区间 + lower_bound 模板，几乎不会写错。
§7 链表链表题考的是指针操作不出错：用 dummy 头节点消除边界、快慢指针找中点/环、画图后再写代码。
§8 二叉树 & BST树题 = 想清楚"递归函数返回什么"。大多数题是后序遍历：先拿到左右子树的结果，再在当前节点合并；BST 题利用中序有序或上下界。
§9 图遍历：BFS / DFS（含网格）DFS 用于"连通性 / 能否到达 / 枚举区域"，BFS 用于无权图最短路和"按步数扩散"。网格是隐式图：四个方向就是边。
§10 拓扑排序 & 并查集有依赖关系（先修课、编译顺序）→ 拓扑排序（Kahn 入度 BFS，同时检测环）；动态合并集合 / 判断连通 / 无向图找环 → 并查集（路径压缩 + 按秩合并，近似 O(1)）。
§11 最短路：Dijkstra / Bellman-Ford非负权单源最短路 → Dijkstra（堆，O(E log V)）；有负权或"最多 k 条边"约束 → Bellman-Ford（按轮松弛，O(kE)）；无权 → BFS；0/1 权 → 0-1 BFS。
§12 堆 / 优先队列"第 k 大 / 前 k 个 / 动态取最值"→ 堆。求最大的 k 个用大小为 k 的最小堆（O(n log k)）；数据流中位数用两个堆。
§13 回溯枚举所有解（子集、排列、组合、棋盘放置）：选择 → 递归 → 撤销。复杂度通常是指数级，关键是剪枝和避免重复。
§14 动态规划DP = 有重叠子问题的递归 + 记忆化。四步：定义状态 → 写转移 → 定 base case → 定计算顺序；先写 @cache 递归版，再改成表格并压缩空间。
§15 区间 & 贪心区间题第一步几乎总是排序：合并按起点排，"选最多不重叠"按终点排。贪心必须能用交换论证（exchange argument）说明为什么局部最优不会错。
§16 Trie & 字符串Trie（前缀树）把一组单词按前缀共享存储，插入/查询 O(L)；用于前缀查询、自动补全、多模式匹配（Word Search II）。和 LLM 的 tokenizer、constrained decoding 直接相关。
§17 位运算 & 数学记住几个恒等式：x ^ x = 0、x & (x-1) 去掉最低位的 1、x & -x 取最低位的 1；快速幂 O(log n)。

最容易写错的 12 个细节

  1. 二分：while lo < hi + hi = mid / lo = mid + 1，区间 [lo, hi)，结果是第一个 True。
  2. BFS：入队时标记 visited；按层处理用 for _ in range(len(q))。
  3. 滑动窗口：求最长在 while 之后更新答案，求最短在 while 之内更新。
  4. 前缀和计数：cnt[0] = 1，先查 cnt[P-k] 再 cnt[P] += 1。
  5. 回溯：res.append(path[:])；同层去重 i > start and a[i] == a[i-1]。
  6. 0/1 背包一维：容量倒序；完全背包正序。组合数：外层物品。
  7. 堆：tuple 里加计数器 tiebreak；最大堆存负数；前 k 大用大小为 k 的最小堆。
  8. Dijkstra：if d > dist[u]: continue 跳过过期条目。
  9. Bellman-Ford 限边数：每轮从上一轮的副本松弛。
  10. 链表：dummy 头；改 next 前先保存；while fast and fast.next。
  11. 树：区分"返回给父节点的值"和"更新全局答案的值"（直径、最大路径和）。
  12. Python：[[0]*n for _ in range(m)]；int(a/b) 向零截断；(x & 1) == 0 要加括号。
